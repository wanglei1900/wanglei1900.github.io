一、Redis基础回顾 ​

1.1 Redis简介 ​

Redis（Remote Dictionary Server）是一个开源、内存中的数据结构存储系统，可用作数据库、缓存和消息中间件。

核心特点：

  • 内存存储，读写性能极高（10万+ OPS）
  • 支持数据持久化（RDB快照、AOF日志）
  • 丰富的数据结构：字符串、列表、集合、有序集合、哈希、位图等
  • 支持事务、Lua脚本、LRU淘汰
  • 发布/订阅模式
  • 主从复制与高可用（哨兵、集群）

1.2 Redis作为键值存储的局限性 ​

  1. 有限的查询能力：只能通过键直接访问，缺乏复杂查询
  2. 无原生全文搜索：需要外部工具（如Elasticsearch）配合
  3. 二级索引需手动实现：通过有序集合等结构模拟，维护复杂
  4. 数据关系处理困难：不适合复杂关联查询

二、RediSearch全面解析 ​

2.1 RediSearch概述 ​

RediSearch是Redis Labs开发的一个Redis模块，为Redis添加了原生全文搜索和二级索引功能。

版本演进：

  • RediSearch 1.x：基本全文搜索功能
  • RediSearch 2.x：重大升级，支持分布式集群
  • 最新版本：2.x系列，与Redis 6.0+兼容性最佳

核心优势：

  • 无需外部依赖，直接集成到Redis
  • 高性能：利用Redis内存特性，延迟极低
  • 实时索引：数据变更立即反映在搜索结果中
  • 丰富的查询语法：支持布尔逻辑、模糊搜索、前缀搜索等
  • 与Redis数据结构无缝集成

2.3.1 安装方式 ​

方式一：Docker部署（推荐）

bash

  -p 6379:6379 -p 8001:8001 \
  redis/redis-stack:latest

# 或单独安装RediSearch模块
docker run -d --name redis-redisearch \
  -p 6379:6379 \

bash
# 下载并编译
git clone --recursive https://github.com/RediSearch/RediSearch.git
cd RediSearch
make setup
make build

# 启动Redis加载模块
redis-server --loadmodule ./bin/redisearch.so

  • Windows/Mac：直接下载安装包

2.4 核心概念 ​

2.4.1 索引（Index） ​

  • 相当于传统数据库的表
  • 定义文档的结构和字段属性
  • 支持自动索引和手动索引

2.4.2 文档（Document） ​

  • 索引中的一条记录
  • 每个文档有唯一ID（可自定义或自动生成）
  • 包含多个字段-值对

2.4.3 字段类型（Field Types） ​

  1. TEXT：全文搜索字段，支持分词
  2. NUMERIC：数值类型，支持范围查询
  3. TAG：标签字段，精确匹配，支持多值
  4. GEO：地理坐标字段
  5. VECTOR：向量字段（用于相似性搜索）

2.4.4 倒排索引（Inverted Index） ​

RediSearch使用倒排索引实现快速全文搜索：

文档集：
Doc1: "Redis is fast"
Doc2: "Redis supports search"
Doc3: "Search is fast"

倒排索引：
"redis" -> [Doc1, Doc2]
"is" -> [Doc1, Doc3]
"fast" -> [Doc1, Doc3]
"supports" -> [Doc2]
"search" -> [Doc2, Doc3]

2.5 基本操作 ​

2.5.1 创建索引 ​

bash
# 基本语法
FT.CREATE {index_name} 
  [ON {structure}] 
  [PREFIX {count} {prefix} [ {prefix} ..]]
  [FILTER {filter}]
  [LANGUAGE {default_lang}]
  [LANGUAGE_FIELD {lang_field}]
  [SCORE {default_score}]
  [SCORE_FIELD {score_field}]
  [PAYLOAD_FIELD {payload_field}]
  [MAXTEXTFIELDS] [TEMPORARY {seconds}]
  [NOOFFSETS] [NOHL] [NOFIELDS] [NOFREQS]
  [STOPWORDS {num} {stopword} ...]
  SCHEMA {field} [TEXT [NOSTEM] [WEIGHT {weight}] [PHONETIC {matcher}]]
           [NUMERIC | TAG | GEO | VECTOR ...]

# 示例：创建商品索引
FT.CREATE idx:products ON HASH PREFIX 1 "product:" 
  SCHEMA
    id TAG
    name TEXT WEIGHT 3.0
    description TEXT WEIGHT 1.0
    category TAG SEPARATOR ","
    price NUMERIC SORTABLE
    stock NUMERIC
    created_at NUMERIC
    tags TAG SEPARATOR ";"
    location GEO

2.5.3 搜索文档 ​

bash
# 基本搜索语法
FT.SEARCH {index_name} 
  "{query}"
  [NOCONTENT]
  [VERBATIM]
  [NOSTOPWORDS]
  [WITHSCORES]
  [WITHPAYLOADS]
  [WITHSORTKEYS]
  [LIMIT offset num]
  [INORDER]
  [LANGUAGE {language}]
  [EXPANDER {expander}]
  [SCORER {scorer}]
  [EXPLAINSCORE]
  [PAYLOAD {payload}]
  [SORTBY {field} [ASC|DESC]]
  [RETURN {num} {field} ...]
  [SUMMARIZE [FIELDS {num} {field} ...] [FRAGS {num}] [LEN {fragsize}] [SEPARATOR {separator}]]
  [HIGHLIGHT [FIELDS {num} {field} ...] [TAGS {open} {close}]]
  [SLOP {slop}] [INKEYS {num} {field} ...]
  [INFIELDS {num} {field} ...]
  [FILTER {field} {min} {max}] ...
  [GEOFILTER {field} {lon} {lat} {radius} {m|km|mi|ft}]
  [NOCONTENT]

# 示例搜索
# 1. 简单全文搜索
FT.SEARCH idx:products "iPhone" RETURN 3 name price stock

# 2. 多词搜索（AND逻辑）
FT.SEARCH idx:products "Apple iPhone" RETURN 3 name price category

# 3. 使用OR逻辑
FT.SEARCH idx:products "Apple | Samsung" RETURN 2 name price

# 4. 字段指定搜索
FT.SEARCH idx:products "@name:iPhone @description:chip" RETURN 3 name description price

# 5. 标签精确搜索
FT.SEARCH idx:products "@category:{Electronics}" RETURN 2 name category

# 6. 多标签搜索
FT.SEARCH idx:products "@category:{Electronics} @tags:{apple}" RETURN 3 name category tags

# 7. 数值范围查询
FT.SEARCH idx:products "@price:[500 1500]" RETURN 3 name price stock

# 8. 组合查询
FT.SEARCH idx:products "(@category:{Electronics}) (@price:[0 1000])" 
  SORTBY price DESC 
  LIMIT 0 10 
  RETURN 4 id name price stock

# 9. 地理搜索
FT.SEARCH idx:products "@location:[-74.006 40.7128 10 km]" RETURN 3 name price location

# 10. 模糊搜索
FT.SEARCH idx:products "%iphone%" RETURN 2 name price

# 11. 前缀搜索
FT.SEARCH idx:products "App*" RETURN 2 name category

2.5.4 聚合查询 ​

bash
# 聚合语法
FT.AGGREGATE {index_name} 
  "{query}"
  [VERBATIM]
  [LOAD {field} ...]
  [GROUPBY {nargs} {property} ...
    REDUCE {func} {nargs} {arg} ... [AS {name}] ...
  ] ...
  [SORTBY {nargs} {property} [ASC|DESC] ... [MAX {num}]]
  [APPLY {expr} AS {alias}] ...
  [LIMIT offset num]
  [FILTER {expr}] ...
  [WITHCURSOR [COUNT read_size] [MAXIDLE idle_time]]
  [TIMEOUT timeout]

# 聚合示例
# 1. 按类别分组统计
FT.AGGREGATE idx:products "*"
  GROUPBY 1 @category
    REDUCE COUNT 0 AS product_count
    REDUCE SUM 1 @price AS total_value
    REDUCE AVG 1 @price AS avg_price
  SORTBY 2 @product_count DESC

# 2. 价格分布分析
FT.AGGREGATE idx:products "*"
  APPLY "floor(@price/100)*100" AS price_range
  GROUPBY 1 @price_range
    REDUCE COUNT 0 AS count
    REDUCE AVG 1 @price AS avg_price
  SORTBY 1 @price_range ASC

# 3. 库存预警
FT.AGGREGATE idx:products "@stock:[0 10]"
  GROUPBY 1 @category
    REDUCE COUNT_DISTINCT 1 @id AS low_stock_items
    REDUCE SUM 1 @stock AS total_stock
  SORTBY 2 @low_stock_items DESC

# 4. 时间序列分析
FT.AGGREGATE idx:products "*"
  APPLY "dayofweek(@created_at)" AS weekday
  GROUPBY 1 @weekday
    REDUCE COUNT 0 AS products_added
  SORTBY 1 @weekday ASC

3.1 电商平台商品搜索 ​

python
# Python示例：电商搜索实现
import redis
from redisearch import Client, TextField, NumericField, TagField

# 连接RediSearch
client = Client("idx:products", host="localhost", port=6379)

# 创建商品索引
try:
    client.create_index([
        TextField("title", weight=5.0),
        TextField("description", weight=1.0),
        TagField("category"),
        TagField("brand"),
        NumericField("price", sortable=True),
        NumericField("rating", sortable=True),
        NumericField("sales", sortable=True),
        TagField("attributes", separator=";")
    ])
except Exception:
    pass  # 索引已存在

# 搜索函数
def search_products(query, category=None, min_price=0, max_price=10000, 
                    sort_by="rating", page=1, page_size=20):
    search_query = query
    
    # 构建过滤条件
    filters = []
    if category:
        filters.append(f"@category:{{{category}}}")
    if min_price > 0 or max_price < 10000:
        filters.append(f"@price:[{min_price} {max_price}]")
    
    # 组合查询
    if filters:
        search_query = f"({search_query}) {' '.join(filters)}"
    
    # 执行搜索
    results = client.search(
        search_query,
        sort_by=sort_by,
        descending=True,
        paging=(page-1)*page_size, page_size
    )
    
    return {
        "total": results.total,
        "products": [dict(doc) for doc in results.docs],
        "page": page,
        "page_size": page_size
    }

  APPLY "regex(@message, 'duration=([0-9.]+)')" AS duration
  APPLY "tonumber(@duration)" AS duration_num
  GROUPBY 1 @service
    REDUCE COUNT 0 AS total_requests
    REDUCE AVG 1 @duration_num AS avg_duration
    REDUCE MAX 1 @duration_num AS max_duration
    REDUCE QUANTILE 2 0.95 @duration_num AS p95_duration

3.3 内容管理系统 ​

javascript
// Node.js示例：文章搜索
const { Client } = require('redis');

class ArticleSearch {
  constructor() {
    this.client = redis.createClient();
    this.searchClient = new Client('idx:articles', this.client);
  }

  async indexArticle(article) {
    // 索引文章
    await this.client.hSet(`article:${article.id}`, {
      id: article.id,
      title: article.title,
      content: article.content,
      author: article.author,
      tags: article.tags.join(';'),
      category: article.category,
      published_at: Math.floor(article.published_at.getTime() / 1000),
      status: article.status
    });
  }

  async searchArticles(query, options = {}) {
    const {
      category,
      author,
      startDate,
      endDate,
      sortBy = 'published_at',
      order = 'DESC',
      page = 1,
      limit = 20
    } = options;

    let searchQuery = query;
    const filters = [];

    if (category) filters.push(`@category:{${category}}`);
    if (author) filters.push(`@author:{${author}}`);
    if (startDate || endDate) {
      const start = startDate ? Math.floor(startDate.getTime() / 1000) : '-inf';
      const end = endDate ? Math.floor(endDate.getTime() / 1000) : '+inf';
      filters.push(`@published_at:[${start} ${end}]`);
    }
    if (filters.length > 0) {
      searchQuery = `(${searchQuery}) ${filters.join(' ')}`;
    }

    const results = await this.searchClient.search(searchQuery, {
      LIMIT: { from: (page - 1) * limit, size: limit },
      SORTBY: { BY: sortBy, DIRECTION: order },
      RETURN: ['id', 'title', 'author', 'category', 'published_at']
    });

    return {
      total: results.total,
      articles: results.documents,
      page,
      totalPages: Math.ceil(results.total / limit)
    };
  }
}

特性RediSearchElasticsearch

延迟亚毫秒级毫秒级
实时性完全实时近实时

方案优点缺点
RediSearch模块原生支持、高性能、功能丰富需要额外模块
RedisJSON + 自定义索引灵活性高实现复杂、维护困难
Redis + Elasticsearch功能强大、生态完善系统复杂、延迟高

  1. 极低延迟：内存存储带来亚毫秒级响应
