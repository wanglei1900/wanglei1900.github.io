MyBatis与动态SQL学习笔记 ​

一、MyBatis概述与核心概念 ​

1.1 MyBatis简介 ​

  • 定位：半自动化ORM框架，介于全自动ORM（如Hibernate）和原生JDBC之间
  • 特点：
    • SQL与代码分离，SQL写在XML中，便于维护和优化
    • 高度灵活，支持复杂SQL和存储过程
    • 学习曲线平缓，迁移成本低
    • 性能接近原生JDBC
  • 与Hibernate对比：
    Hibernate特点：
- 全自动ORM，自动生成SQL
- 对象关系映射完善
- 适合快速开发、简单CRUD
- 复杂的查询和性能优化较困难

MyBatis特点：
- 半自动ORM，手动编写SQL
- 灵活控制SQL，支持复杂查询
- 性能调优更容易
- 适合复杂业务场景、报表查询

1.2 MyBatis核心组件 ​

1.2.1 架构图 ​

应用程序
    ↓
SqlSessionFactoryBuilder
    ↓
SqlSessionFactory (单例)
    ↓
SqlSession (每个线程一个，非线程安全)
    ↓
Executor (执行器：Simple、Reuse、Batch)
    ↓
MappedStatement (SQL映射)
    ↓
数据库

1.2.2 核心接口和类 ​

java
// 1. SqlSessionFactoryBuilder
// 用于构建SqlSessionFactory
String resource = "mybatis-config.xml";
InputStream inputStream = Resources.getResourceAsStream(resource);
SqlSessionFactory sqlSessionFactory = new SqlSessionFactoryBuilder().build(inputStream);

// 2. SqlSessionFactory
// 线程安全的工厂，应用生命周期内保持单例
// 创建SqlSession
SqlSession session = sqlSessionFactory.openSession();

// 3. SqlSession
// 主要接口，提供CRUD方法，线程不安全
// 常用方法：
// - selectOne, selectList, selectMap
// - insert, update, delete
// - commit, rollback
// - getMapper

// 4. Executor
// SQL执行器，有三种类型：
// - SIMPLE: 默认，每次执行创建新的PreparedStatement
// - REUSE: 复用PreparedStatement
// - BATCH: 批量操作，需要手动提交

2.1 配置文件结构 ​

xml
<!-- mybatis-config.xml -->
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE configuration
    PUBLIC "-//mybatis.org//DTD Config 3.0//EN"
    "http://mybatis.org/dtd/mybatis-3-config.dtd">
<configuration>
    <!-- 1. 属性配置 -->
    <properties resource="db.properties">
        <property name="username" value="root"/>
    </properties>
    
    <!-- 2. 设置 -->
    <settings>
        <setting name="cacheEnabled" value="true"/>
        <setting name="lazyLoadingEnabled" value="true"/>
        <setting name="mapUnderscoreToCamelCase" value="true"/>
        <setting name="defaultExecutorType" value="REUSE"/>
        <setting name="logImpl" value="SLF4J"/>
    </settings>
    
    <!-- 3. 类型别名 -->
    <typeAliases>
        <package name="com.example.model"/>
        <typeAlias alias="User" type="com.example.model.User"/>
    </typeAliases>
    
    <!-- 4. 类型处理器 -->
    <typeHandlers>
        <typeHandler handler="com.example.handler.LocalDateTimeTypeHandler"/>
    </typeHandlers>
    
    <!-- 5. 插件 -->
    <plugins>
        <plugin interceptor="com.example.plugin.SqlCostInterceptor"/>
    </plugins>
    
    <!-- 6. 环境配置 -->
    <environments default="development">
        <environment id="development">
            <transactionManager type="JDBC"/>
            <dataSource type="POOLED">
                <property name="driver" value="${driver}"/>
                <property name="url" value="${url}"/>
                <property name="username" value="${username}"/>
                <property name="password" value="${password}"/>
            </dataSource>
        </environment>
    </environments>
    
    <!-- 7. 数据库厂商标识 -->
    <databaseIdProvider type="DB_VENDOR">
        <property name="MySQL" value="mysql"/>
        <property name="Oracle" value="oracle"/>
    </databaseIdProvider>
    
    <!-- 8. 映射器 -->
    <mappers>
        <mapper resource="mapper/UserMapper.xml"/>
        <package name="com.example.mapper"/>
    </mappers>
</configuration>

三、Mapper XML映射文件 ​

3.1 基础映射 ​

xml
<!-- UserMapper.xml -->
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper
    PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
    "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="com.example.mapper.UserMapper">
    
    <!-- 1. 结果映射 -->
    <resultMap id="UserResultMap" type="User">
        <!-- 主键映射 -->
        <id property="id" column="id" jdbcType="BIGINT"/>
        
        <!-- 普通字段映射 -->
        <result property="username" column="username" jdbcType="VARCHAR"/>
        <result property="email" column="email" jdbcType="VARCHAR"/>
        <result property="age" column="age" jdbcType="INTEGER"/>
        
        <!-- Java 8日期类型 -->
        <result property="createdAt" column="created_at" 
                typeHandler="org.apache.ibatis.type.LocalDateTimeTypeHandler"/>
        
        <!-- 枚举类型 -->
        <result property="status" column="status" 
                typeHandler="org.apache.ibatis.type.EnumTypeHandler"/>
    </resultMap>
    
    <!-- 2. SQL片段 -->
    <sql id="Base_Column_List">
        id, username, email, age, created_at
    </sql>
    
    <sql id="Where_Active">
        WHERE status = 'ACTIVE'
    </sql>
    
    <!-- 3. 基础CRUD -->
    <!-- 查询 -->
    <select id="selectById" parameterType="Long" resultMap="UserResultMap">
        SELECT <include refid="Base_Column_List"/>
        FROM users
        WHERE id = #{id}
    </select>
    
    <!-- 插入 -->
    <insert id="insert" parameterType="User" useGeneratedKeys="true" keyProperty="id">
        INSERT INTO users (username, email, age, created_at)
        VALUES (#{username}, #{email}, #{age}, #{createdAt})
    </insert>
    
    <!-- 批量插入 -->
    <insert id="batchInsert" parameterType="java.util.List">
        INSERT INTO users (username, email, age)
        VALUES
        <foreach collection="list" item="user" separator=",">
            (#{user.username}, #{user.email}, #{user.age})
        </foreach>
    </insert>
    
    <!-- 更新 -->
    <update id="update" parameterType="User">
        UPDATE users
        SET username = #{username},
            email = #{email},
            age = #{age}
        WHERE id = #{id}
    </update>
    
    <!-- 删除 -->
    <delete id="deleteById" parameterType="Long">
        DELETE FROM users WHERE id = #{id}
    </delete>
    
    <!-- 4. 参数映射 -->
    <select id="selectByCondition" parameterType="map" resultMap="UserResultMap">
        SELECT <include refid="Base_Column_List"/>
        FROM users
        WHERE 1=1
        <if test="username != null">
            AND username = #{username}
        </if>
        <if test="minAge != null">
            AND age >= #{minAge}
        </if>
        <if test="maxAge != null">
            AND age <= #{maxAge}
        </if>
        ORDER BY
        <choose>
            <when test="orderBy == 'age'">
                age
            </when>
            <when test="orderBy == 'username'">
                username
            </when>
            <otherwise>
                id
            </otherwise>
        </choose>
        <if test="order != null">
            ${order}
        </if>
    </select>
</mapper>

3.2 高级结果映射 ​

3.2.1 一对一关联 ​

xml
<!-- 嵌套结果映射 -->
<resultMap id="OrderWithUserResultMap" type="Order" extends="BaseOrderResultMap">
    <!-- 一对一关联 -->
    <association property="user" javaType="User" resultMap="UserResultMap"/>
    
    <!-- 或内联映射 -->
    <association property="user" javaType="User">
        <id property="id" column="user_id"/>
        <result property="username" column="username"/>
        <result property="email" column="email"/>
    </association>
</resultMap>

<select id="selectOrderWithUser" resultMap="OrderWithUserResultMap">
    SELECT o.*, u.id as user_id, u.username, u.email
    FROM orders o
    LEFT JOIN users u ON o.user_id = u.id
    WHERE o.id = #{id}
</select>

<!-- 嵌套查询（N+1问题，慎用） -->
<resultMap id="OrderWithUserNestedResultMap" type="Order">
    <id property="id" column="id"/>
    <!-- 其他字段映射 -->
    
    <association property="user" column="user_id" 
                 javaType="User" select="selectUserById"/>
</resultMap>

<select id="selectOrderWithUserNested" resultMap="OrderWithUserNestedResultMap">
    SELECT * FROM orders WHERE id = #{id}
</select>

<select id="selectUserById" resultType="User">
    SELECT * FROM users WHERE id = #{id}
</select>

3.2.2 一对多关联 ​

xml
<resultMap id="UserWithOrdersResultMap" type="User" extends="UserResultMap">
    <!-- 一对多关联 -->
    <collection property="orders" ofType="Order">
        <id property="id" column="order_id"/>
        <result property="orderNo" column="order_no"/>
        <result property="amount" column="amount"/>
        <result property="createdAt" column="order_created_at"/>
    </collection>
</resultMap>

<select id="selectUserWithOrders" resultMap="UserWithOrdersResultMap">
    SELECT 
        u.*,
        o.id as order_id,
        o.order_no,
        o.amount,
        o.created_at as order_created_at
    FROM users u
    LEFT JOIN orders o ON u.id = o.user_id
    WHERE u.id = #{id}
</select>

<!-- 嵌套查询的分页问题解决方案 -->
<resultMap id="UserWithOrdersLazyResultMap" type="User">
    <id property="id" column="id"/>
    <!-- 其他字段 -->
    
    <collection property="orders" column="{userId=id}" 
                ofType="Order" select="selectOrdersByUserId"
                fetchType="lazy"/>
</resultMap>

// 1. 实现Interceptor接口
@Intercepts({
    @Signature(
        type = Executor.class,
        method = "query",
        args = {MappedStatement.class, Object.class, RowBounds.class, ResultHandler.class}
    ),
    @Signature(
        type = Executor.class,
        method = "update",
        args = {MappedStatement.class, Object.class}
    )
})
public class SqlCostInterceptor implements Interceptor {
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        long startTime = System.currentTimeMillis();
        
        try {
            return invocation.proceed();
        } finally {
            long cost = System.currentTimeMillis() - startTime;
            Object[] args = invocation.getArgs();
            MappedStatement mappedStatement = (MappedStatement) args[0];
            String sqlId = mappedStatement.getId();
            
            if (cost > 1000) {  // 超过1秒的SQL
                log.warn("Slow SQL detected: {} - {} ms", sqlId, cost);
            }
            
            log.debug("SQL: {} - {} ms", sqlId, cost);
        }
    }
    
    @Override
    public Object plugin(Object target) {
        return Plugin.wrap(target, this);
    }
    
    @Override
    public void setProperties(Properties properties) {
        // 读取配置属性
    }
}

// 2. 分页插件示例
@Intercepts(@Signature(
    type = StatementHandler.class,
    method = "prepare",
    args = {Connection.class, Integer.class}
))
public class PaginationInterceptor implements Interceptor {
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        StatementHandler handler = (StatementHandler) invocation.getTarget();
        
        // 获取BoundSql
        BoundSql boundSql = handler.getBoundSql();
        String sql = boundSql.getSql();
        
        // 获取分页参数
        Object param = boundSql.getParameterObject();
        if (param instanceof Map) {
            Map<?, ?> paramMap = (Map<?, ?>) param;
            Page<?> page = (Page<?>) paramMap.get("page");
            
            if (page != null) {
                // 修改SQL添加分页
                String pageSql = getPageSql(sql, page);
                
                // 通过反射修改BoundSql的sql字段
                Field sqlField = BoundSql.class.getDeclaredField("sql");
                sqlField.setAccessible(true);
                sqlField.set(boundSql, pageSql);
            }
        }
        
        return invocation.proceed();
    }
    
    private String getPageSql(String sql, Page<?> page) {
        // 根据数据库类型生成分页SQL
        // MySQL: LIMIT #{offset}, #{limit}
        // Oracle: ROWNUM等
        return sql + " LIMIT " + page.getOffset() + ", " + page.getLimit();
    }
}

// 3. 乐观锁插件
@Intercepts(@Signature(
    type = Executor.class,
    method = "update",
    args = {MappedStatement.class, Object.class}
))
public class OptimisticLockInterceptor implements Interceptor {
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        Object[] args = invocation.getArgs();
        MappedStatement ms = (MappedStatement) args[0];
        Object parameter = args[1];
        
        // 检查实体是否有@Version注解
        if (parameter != null && hasVersionField(parameter)) {
            // 在执行更新前检查版本号
            checkVersion(ms, parameter);
        }
        
        return invocation.proceed();
    }
}

java
// 1. SQL执行监控
@Aspect
@Component
@Slf4j
public class MyBatisMonitorAspect {
    
    @Around("execution(* com.example.mapper.*.*(..))")
    public Object monitorSqlExecution(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();
        String methodName = joinPoint.getSignature().toShortString();
        
        try {
            return joinPoint.proceed();
        } finally {
            long cost = System.currentTimeMillis() - startTime;
            
            if (cost > 1000) {
                log.warn("Slow MyBatis method: {} - {} ms", methodName, cost);
            }
            
            // 记录到监控系统
            Metrics.timer("mybatis.method.duration")
                .tag("method", methodName)
                .record(cost, TimeUnit.MILLISECONDS);
        }
    }
}

// 2. 慢SQL日志
@Intercepts(@Signature(
    type = StatementHandler.class,
    method = "query",
    args = {Statement.class, ResultHandler.class}
))
public class SlowSqlInterceptor implements Interceptor {
    
    private static final long SLOW_SQL_THRESHOLD = 1000; // 1秒
    
    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        long startTime = System.currentTimeMillis();
        
        try {
            return invocation.proceed();
        } finally {
            long cost = System.currentTimeMillis() - startTime;
            
            if (cost > SLOW_SQL_THRESHOLD) {
                StatementHandler handler = (StatementHandler) invocation.getTarget();
                BoundSql boundSql = handler.getBoundSql();
                
                log.warn("Slow SQL detected: \nSQL: {}\nParameters: {}\nCost: {} ms",
                    boundSql.getSql(),
                    boundSql.getParameterObject(),
                    cost);
            }
        }
    }
}

public class UserService extends ServiceImpl<UserMapper, User> {
    
    // 分页查询
    public Page<User> pageUsers(Page<User> page, UserQuery query) {
        return lambdaQuery()
            .like(StringUtils.isNotBlank(query.getUsername()), 
                  User::getUsername, query.getUsername())
            .ge(query.getMinAge() != null, User::getAge, query.getMinAge())
            .le(query.getMaxAge() != null, User::getAge, query.getMaxAge())
            .orderByDesc(User::getId)
            .page(page);
    }
    
    // 批量操作
    public boolean saveOrUpdateBatch(List<User> userList) {
        return saveOrUpdateBatch(userList, 1000); // 每批1000条
    }
}

总结 ​

MyBatis作为一个半自动化的ORM框架，在灵活性和性能之间取得了良好的平衡。通过掌握MyBatis的核心配置、动态SQL、缓存机制和插件开发，可以构建出高效、可维护的数据访问层。

关键最佳实践： ​

  1. SQL优化：避免SELECT *，合理使用索引，优化复杂查询
  2. 批量操作：使用Batch执行器，合理设置批次大小
  3. 缓存策略：合理使用一级和二级缓存，注意缓存一致性
  4. 事务管理：合理设置事务边界，避免长事务
  5. 监控与诊断：监控慢SQL，定期分析执行计划
  6. 代码规范：SQL与Java代码分离，使用Mapper接口

选择建议： ​

  • 简单CRUD场景：推荐使用MyBatis-Plus，提高开发效率
  • 复杂SQL场景：推荐使用原生MyBatis，灵活控制SQL
  • 微服务架构：结合Spring Boot，使用MyBatis Starter
  • 传统项目：使用XML配置，便于SQL维护和优化

MyBatis凭借其灵活性和高性能，在企业级应用中仍然占有重要地位。通过合理使用MyBatis的特性，可以构建出既灵活又高效的数据访问层。
