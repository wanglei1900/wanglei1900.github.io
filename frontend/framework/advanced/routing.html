1. 路由核心概念 ​

1.1 路由基本要素 ​

javascript
const routeConfig = {
  path: '/users/:id',       // 路径匹配规则
  component: UserDetail,    // 渲染组件
  children: [/* 嵌套路由 */], // 子路由
  guards: [authGuard],      // 路由守卫
  data: { requiresAuth: true } // 路由元数据
}

1.2 路由关键术语 ​

  • 路径匹配：URL与路由配置的映射关系
  • 动态路由：/users/:id 形式的参数化路由
  • 嵌套路由：父子层级的路由结构
  • 路由守卫：导航前后的拦截逻辑
  • 路由懒加载：按需加载路由组件
  • 路由元数据：附加到路由的额外信息

1.3 路由生命周期 ​

mermaid
graph LR
A[导航触发] --> B[路由守卫检查]
B --> C[卸载当前组件]
C --> D[解析目标路由]
D --> E[加载异步组件]
E --> F[激活新组件]
F --> G[更新URL]

2. 路由模式对比 ​

2.1 Hash模式 ​

javascript
// URL示例：http://example.com/#/users/123
window.location.hash = '#/users/123'; 
window.addEventListener('hashchange', () => {
  const path = window.location.hash.substring(1);
  // 处理路由...
});

特点：

  • 兼容性好（支持IE8+）
  • 无需服务器配置
  • URL中包含#符号
  • SEO不友好

2.2 History模式 ​

javascript
// URL示例：http://example.com/users/123
history.pushState({}, '', '/users/123');
window.addEventListener('popstate', () => {
  const path = window.location.pathname;
  // 处理路由...
});

特点：

  • 干净的URL（无#）
  • SEO友好
  • 需要服务器支持（配置回退路由）
  • 兼容性：IE10+（需要polyfill）

2.3 Memory模式 ​

javascript
// 无URL变化，内部维护路由状态
const history = createMemoryHistory();
history.push('/users/123');

适用场景：

  • 移动端原生应用（React Native）
  • 浏览器扩展程序
  • 测试环境

3. 主流路由库解析 ​

3.1 React Router (v6) ​

jsx
// 基础配置
<Routes>
  <Route path="/" element={<Layout />}>
    <Route index element={<Home />} />
    <Route path="users" element={<Users />}>
      <Route path=":id" element={<UserDetail />} />
    </Route>
    <Route path="*" element={<NotFound />} />
  </Route>
</Routes>

// 编程式导航
const navigate = useNavigate();
navigate('/users/123', { state: { fromHome: true } });

// 路由守卫
<Route 
  path="/admin" 
  element={<RequireAuth><Admin /></RequireAuth>} 
/>

3.2 Vue Router (v4) ​

javascript
// 路由配置
const routes = [
  { path: '/', component: Home },
  { 
    path: '/users', 
    component: Users,
    children: [
      { path: ':id', component: UserDetail }
    ]
  }
]

// 路由守卫
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isAuthenticated) {
    return { path: '/login' }
  }
})

// 动态路由
router.addRoute({
  path: '/new-route',
  component: NewComponent
})

4. 高级路由模式 ​

4.1 路由状态管理 ​

javascript
// 使用URL作为状态存储
/users?sort=name&filter=active

// 同步URL与状态
const [filters, setFilters] = useState(() => {
  const params = new URLSearchParams(location.search);
  return {
    sort: params.get('sort') || 'name',
    filter: params.get('filter') || 'all'
  };
});

// 状态变更更新URL
const updateFilters = (newFilters) => {
  setFilters(newFilters);
  navigate(`?${new URLSearchParams(newFilters)}`);
}

4.2 基于文件的路由 ​

markdown
// 文件结构即路由
src/
  pages/
    index.tsx       -> /
    users/
      index.tsx     -> /users
      [id].tsx      -> /users/:id
    admin/
      dashboard.tsx -> /admin/dashboard

实现库：

  • Next.js：开箱即用
  • Vite：使用vite-plugin-pages
  • React：react-location或@tanstack/react-router

6. 路由最佳实践 ​

6.1 路由结构设计原则 ​

  1. 扁平化结构：不超过3层嵌套
  2. 语义化路径：/users/123/profile优于/app?view=profile&id=123
  3. 版本控制：/v1/users支持API演进
  4. 权限分离：公共路由与私有路由分开配置

6.2 路由配置模式 ​

javascript
// 集中式配置
const routes = [
  { path: '/', component: Home },
  { path: '/about', component: About }
];

// 文件系统路由（Next.js示例）
// pages/index.tsx -> /
// pages/users/index.tsx -> /users
// pages/users/[id].tsx -> /users/:id

// 混合模式（主路由集中，模块路由分散）
app/
  modules/
    users/
      routes.js // 导出用户模块路由
  routes.js // 聚合所有模块路由

6.3 错误处理 ​

jsx
// 404处理
<Route path="*" element={<NotFound />} />

// 错误边界（React）
<ErrorBoundary>
  <Routes>...</Routes>
</ErrorBoundary>

// 路由级错误处理（Vue）
router.onError((error) => {
  if (error.name === 'ChunkLoadError') {
    showReloadPageDialog();
  }
})

7. 常见问题解决方案 ​

7.1 滚动位置恢复 ​

javascript
// 保存滚动位置
window.addEventListener('popstate', () => {
  sessionStorage.setItem(
    `scrollPos:${location.pathname}`, 
    window.scrollY
  );
});

// 恢复滚动位置
useEffect(() => {
  const savedPosition = sessionStorage.getItem(
    `scrollPos:${location.pathname}`
  );
  window.scrollTo(0, savedPosition || 0);
}, [location]);

7.2 路由冲突处理 ​

javascript
// 路由优先级调整
const routes = [
  { path: '/users/new' }, // 高优先级
  { path: '/users/:id' }  // 低优先级
];

// 精确匹配
<Route exact path="/users" />

// 查询参数处理
const useQueryParams = () => {
  const location = useLocation();
  return new URLSearchParams(location.search);
}

7.3 身份验证流程 ​

javascript
// 认证守卫
const authGuard = (to, from, next) => {
  if (to.meta.requiresAuth) {
    if (isAuthenticated()) {
      next();
    } else {
      next({ path: '/login', query: { redirect: to.fullPath } });
    }
  } else {
    next();
  }
}

// 登录后重定向
const redirect = router.query.redirect || '/';
router.push(redirect);

8. 未来路由趋势 ​

8.1 服务端组件路由 ​

jsx
// Next.js App Router示例
// app/page.js - 服务端组件
export default async function Page() {
  const data = await fetchData();
  return <ClientComponent data={data} />;
}

// app/client-component.js
'use client'; // 客户端组件
export default function ClientComponent({ data }) {
  return <div>{data}</div>;
}

8.2 类型安全路由 ​

typescript
// 使用类型化路由库（如: @tanstack/react-router）
const router = createRouter({
  routes: {
    userDetail: {
      path: '/users/$userId',
      component: UserDetail
    }
  }
});

// 类型安全的导航
router.navigate({ to: '/users/$userId', params: { userId: '123' } });

8.3 基于AI的路由优化 ​

  • 智能预加载：预测用户下一步行为
  • 自适应路由：基于设备能力的路由分发
  • A/B测试路由：自动化路由版本测试

路由库选择建议：

  • 大型应用：React Router / Vue Router
  • 静态站点：Next.js / Nuxt.js 文件路由
  • 极致性能：SvelteKit / SolidStart
  • 微前端：single-spa / qiankun
