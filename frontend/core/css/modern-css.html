现代CSS方案学习笔记 ​

一、CSS布局演进 ​

mermaid
graph LR
A[表格布局] --> B[浮动布局]
B --> C[定位布局]
C --> D[Flex布局]
D --> E[Grid布局]
E --> F[混合布局方案]

  • 传统布局方式：

    • 表格布局：<table>标签
    • 浮动布局：float属性
    • 定位布局：position属性

  • 现代布局方式：

    • Flexbox（一维布局）
    • CSS Grid（二维布局）
    • 多列布局（column-count）

关键转变：从Hacky解决方案到语义化、声明式的布局方案

二、Flexbox弹性布局 ​

核心概念 ​

css
.container {
  display: flex;
  flex-direction: row; /* 主轴方向 */
  justify-content: center; /* 主轴对齐 */
  align-items: center; /* 交叉轴对齐 */
  flex-wrap: wrap; /* 换行 */
}

.item {
  flex: 1; /* 弹性因子 */
  order: 2; /* 显示顺序 */
  align-self: flex-end; /* 单独对齐 */
}

适用场景 ​

  • 一维布局（单行或单列）
  • 内容动态大小的容器
  • 垂直居中
  • 等高分栏

浏览器支持：所有现代浏览器（IE10+部分支持）

三、Grid网格布局 ​

基本结构 ​

css
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr; /* 列定义 */
  grid-template-rows: 100px auto; /* 行定义 */
  gap: 20px; /* 间距 */
  grid-template-areas: 
    "header header header"
    "sidebar main aside"
    "footer footer footer";
}

.header { grid-area: header; }
.main { grid-area: main; }

关键特性 ​

  • 二维布局系统
  • 显式网格与隐式网格
  • 灵活的轨道尺寸（fr单位）
  • 网格区域命名
  • 强大的对齐控制

典型用例：复杂仪表盘、杂志式布局、卡片网格

四、响应式设计 ​

核心技术 ​

  1. 媒体查询：

    css
    @media (max-width: 768px) {
  .container { flex-direction: column; }
}

  2. 响应式单位：

    • vw/vh：视口百分比
    • rem：根元素相对大小
    • %：容器百分比

  3. 响应式图片：

    html
    <img srcset="small.jpg 480w, large.jpg 1080w"
     sizes="(max-width: 600px) 480px, 1080px"
     src="large.jpg">

移动优先策略 ​

css
/* 基础样式（移动端） */
.container { padding: 10px; }

/* 中等屏幕 */
@media (min-width: 768px) { ... }

/* 大屏幕 */
@media (min-width: 1024px) { ... }

五、CSS变量与自定义属性 ​

定义与使用 ​

css
:root {
  --primary-color: #3498db;
  --spacing-unit: 8px;
}

.button {
  background-color: var(--primary-color);
  padding: calc(var(--spacing-unit) * 2);
}

优势 ​

  • 主题切换能力
  • 动态计算值
  • 减少重复代码
  • JavaScript交互性：
    js
    document.documentElement.style.setProperty('--primary-color', '#e74c3c');

六、CSS预处理与后处理 ​

预处理器（Sass示例） ​

scss
// 变量
$primary: #3498db;

// 嵌套
.container {
  .item {
    color: $primary;
    
    &:hover {
      opacity: 0.8;
    }
  }
}

// Mixin
@mixin center-flex {
  display: flex;
  justify-content: center;
  align-items: center;
}

.header {
  @include center-flex;
}

后处理器（PostCSS） ​

javascript
// postcss.config.js
module.exports = {
  plugins: [
    require('autoprefixer'), // 自动添加前缀
    require('cssnano')       // 代码压缩
  ]
}

工具对比 ​

类型代表工具主要功能
预处理器Sass, Less变量, 嵌套, Mixin
后处理器PostCSS自动前缀, 代码优化

七、CSS-in-JS方案 ​

核心思想 ​

javascript
import styled from 'styled-components';

const Button = styled.button`
  background: ${props => props.primary ? '#3498db' : 'white'};
  padding: 12px 24px;
  border-radius: 4px;
  border: none;
  cursor: pointer;
  
  &:hover {
    opacity: 0.9;
  }
`;

// 使用
<Button primary>主要按钮</Button>

主流库 ​

  1. Styled Components：模板字符串样式
  2. Emotion：高性能CSS-in-JS
  3. JSS：JavaScript对象写样式

优势 ​

  • 组件作用域样式
  • 动态样式（基于props）
  • 自动厂商前缀
  • 自动关键CSS提取

1. 重置与标准化 ​

css

  box-sizing: border-box;
  margin: 0;
  padding: 0;

2. 实用类优先（Utility-First） ​

html

3. 性能优化 ​

  • 避免深层嵌套选择器
  • 使用will-change优化动画
  • 关键CSS内联
  • 异步加载非关键CSS

4. 无障碍设计 ​

css
/* 焦点样式 */
*:focus-visible {
  outline: 2px solid var(--primary-color);
  outline-offset: 2px;
}

/* 减少动画 */
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

5. 现代特性使用 ​

css
/* 容器查询 */

  .card { display: flex; }
}

/* 级联层 */
@layer base, theme, utilities;

@layer base {
  /* 基础样式 */
}

@layer utilities {
  .text-center { text-align: center; }
}
