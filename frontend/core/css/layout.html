CSS 布局系统全面学习笔记 ​

一、CSS 布局系统概述 ​

1. 布局发展历程 ​

mermaid
timeline
    title CSS布局技术演进
    1996 ： 表格布局
    2003 ： 浮动布局
    2006 ： 定位布局
    2009 ： 弹性盒模型(Flexbox)草案
    2012 ： Grid布局草案
    2017 ： Flexbox和Grid成为标准

2. 核心布局技术对比 ​

技术适用场景核心特点浏览器支持
传统布局简单布局基于文档流全支持
Flexbox一维布局弹性容器IE10+
Grid二维布局网格系统IE11+ (部分)
多列布局文本分栏类似报纸布局IE10+
定位布局特殊定位脱离文档流全支持

二、传统布局技术 ​

1. 文档流布局 ​

css
/* 基础文档流 */
.block-element {
  display: block; /* div, p, h1等 */
  width: 100%;
}

.inline-element {
  display: inline; /* span, a, strong等 */
  margin: 0 5px;
}

.inline-block-element {
  display: inline-block; /* 兼具两者特性 */
  width: 200px;
}

2. 浮动布局 ​

css
/* 经典浮动布局 */
.container {
  overflow: auto; /* 清除浮动 */
}

.left-column {
  float: left;
  width: 25%;
}

.right-column {
  float: right;
  width: 75%;
}

/* 清除浮动技巧 */
.clearfix::after {
  content: "";
  display: table;
  clear: both;
}

3. 定位布局 ​

css
/* 定位类型 */
.relative-box {
  position: relative; /* 相对定位 */
  top: 10px;
  left: 20px;
}

.absolute-box {
  position: absolute; /* 绝对定位 */
  top: 0;
  right: 0;
}

.fixed-box {
  position: fixed; /* 固定定位 */
  bottom: 20px;
  right: 20px;
}

.sticky-box {
  position: sticky; /* 粘性定位 */
  top: 0;
}

三、Flexbox 弹性布局 ​

1. Flex 容器属性 ​

css
.flex-container {
  display: flex; /* 定义弹性容器 */
  
  /* 主轴方向 */
  flex-direction: row | row-reverse | column | column-reverse;
  
  /* 换行规则 */
  flex-wrap: nowrap | wrap | wrap-reverse;
  
  /* 主轴对齐 */
  justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
  
  /* 交叉轴对齐 */
  align-items: stretch | flex-start | flex-end | center | baseline;
  
  /* 多行对齐 */
  align-content: stretch | flex-start | flex-end | center | space-between | space-around;
}

2. Flex 项目属性 ​

css
.flex-item {
  /* 项目排序 */
  order: 0; /* 默认值 */
  
  /* 放大比例 */
  flex-grow: 0; 
  
  /* 缩小比例 */
  flex-shrink: 1;
  
  /* 初始尺寸 */
  flex-basis: auto | <length>;
  
  /* 简写属性 */
  flex: 0 1 auto; /* [grow] [shrink] [basis] */
  
  /* 单独对齐 */
  align-self: auto | stretch | flex-start | flex-end | center | baseline;
}

3. Flex 布局实战 ​

html
<div class="flex-container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
css
.flex-container {
  display: flex;
  gap: 10px; /* 项目间距 */
  padding: 20px;
  background: #f0f0f0;
  min-height: 300px;
}

.item {
  flex: 1; /* 等分空间 */
  background: #3498db;
  color: white;
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 24px;
}

四、Grid 网格布局 ​

1. Grid 容器属性 ​

css
.grid-container {
  display: grid; /* 定义网格容器 */
  
  /* 定义列 */
  grid-template-columns: 100px 1fr 2fr;
  
  /* 定义行 */
  grid-template-rows: auto 1fr auto;
  
  /* 区域模板 */
  grid-template-areas: 
    "header header header"
    "sidebar content content"
    "footer footer footer";
  
  /* 间距 */
  gap: 20px; /* row-gap column-gap */
  
  /* 对齐方式 */
  justify-items: stretch | start | end | center;
  align-items: stretch | start | end | center;
  
  /* 容器整体对齐 */
  justify-content: start | end | center | stretch | space-around | space-between | space-evenly;
  align-content: start | end | center | stretch | space-around | space-between | space-evenly;
}

2. Grid 项目属性 ​

css
.grid-item {
  /* 项目位置 */
  grid-column-start: 1;
  grid-column-end: 3;
  grid-row-start: 1;
  grid-row-end: 2;
  
  /* 简写 */
  grid-column: 1 / span 2;
  grid-row: 1 / 2;
  
  /* 区域分配 */
  grid-area: header;
  
  /* 单独对齐 */
  justify-self: stretch | start | end | center;
  align-self: stretch | start | end | center;
}

五、响应式布局技术 ​

1. 媒体查询 ​

css
/* 移动优先设计 */
.container {
  width: 100%;
  padding: 10px;
}

/* 平板设备 */
@media (min-width: 768px) {
  .container {
    width: 750px;
    margin: 0 auto;
  }
}

/* 桌面设备 */
@media (min-width: 992px) {
  .container {
    width: 970px;
  }
}

/* 大屏幕 */
@media (min-width: 1200px) {
  .container {
    width: 1170px;
  }
}

2. 响应式单位 ​

单位描述使用场景
%相对于父元素宽度、高度
vw视口宽度的1%全屏元素
vh视口高度的1%全屏元素
vminvw和vh中较小的值移动设备适配
vmaxvw和vh中较大的值桌面设备适配
rem相对于根元素字体大小响应式排版
em相对于当前元素字体大小内边距、外边距

3. 响应式布局模式 ​

css
/* Flexbox响应式布局 */
.responsive-flex {
  display: flex;
  flex-wrap: wrap;
}

.responsive-flex > div {
  flex: 1 1 300px; /* 最小宽度300px */
  margin: 10px;
}

/* Grid响应式布局 */
.responsive-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

九、布局性能优化 ​

1. 布局性能优化策略 ​

策略描述实现方式
避免重排减少布局计算使用transform代替top/left
使用contain属性限制布局影响范围contain: layout;
虚拟滚动只渲染可见内容大型列表优化
避免布局抖动批量DOM操作使用requestAnimationFrame
优化CSS选择器减少复杂选择器避免嵌套过深

2. 优化示例 ​

十一、布局最佳实践 ​

1. 布局选择指南 ​

mermaid
graph TD
    A[需要布局？] --> B{布局维度}
    B -->|一维| C[Flexbox]
    B -->|二维| D[Grid]
    C --> E{简单响应式}
    D --> F{复杂响应式}
    E -->|是| G[Flexbox]
    E -->|否| H[Grid]

2. 通用布局原则 ​

  1. 移动优先设计：从小屏幕开始，逐步增强
  2. 渐进增强：确保基本功能在旧浏览器可用
  3. 语义化结构：HTML结构优先，CSS布局其次
  4. 性能优先：避免过度复杂的布局计算
  5. 可维护性：使用一致的命名和结构
