E2E 测试（Cypress & Playwright）学习笔记 ​

为什么需要 E2E 测试？ ​

关键价值 ​

  • 用户行为模拟：真实模拟用户操作流程
  • 全栈验证：验证前端、后端、数据库和网络协同工作
  • 关键路径保障：确保核心业务流程（注册、登录、支付）稳定
  • 视觉回归检测：捕捉意外的UI变化
  • 质量信心：发布前对关键功能进行最终验证

测试金字塔中的位置 ​

       / \
      / E2E \   <-- 少量高层次测试
     /--------\
    / Integration \
   /----------------\
  /     Unit Tests    \  <-- 大量低层次测试
 /---------------------\

Cypress vs Playwright 对比 ​

特性CypressPlaywright
架构基于浏览器跨浏览器引擎
语言支持JavaScript/TypeScriptJavaScript/TypeScript/Java/Python/C#
执行速度中等⚡ 快（并行执行）
多标签页支持有限✅ 完整支持
网络控制✅✅ 更强大
移动设备测试有限✅ 完整模拟
录制功能✅✅
社区生态成熟丰富快速成长
学习曲线平缓中等

核心概念 ​

测试结构 ​

javascript
// Cypress 示例
describe('登录功能', () => {
  beforeEach(() => {
    cy.visit('/login');
  });

  it('使用有效凭证应成功登录', () => {
    cy.get('#email').type('user@example.com');
    cy.get('#password').type('password123');
    cy.get('form').submit();
    cy.url().should('include', '/dashboard');
  });
});

// Playwright 示例
test('购物车流程', async ({ page }) => {
  await page.goto('https://store.example.com');
  await page.click('#product-123');
  await page.click('#add-to-cart');
  await page.click('#checkout');
  
  await expect(page).toHaveURL(/checkout/);
  await expect(page.locator('.cart-item')).toHaveCount(1);
});

关键操作模式 ​

  1. 定位元素：

    • Cypress：cy.get('.selector') / cy.contains('Text')
    • Playwright：page.locator('text=Submit') / page.getByRole('button')

  2. 用户交互：

    javascript
    // 点击
cy.get('button').click();          // Cypress
await page.click('button');        // Playwright

// 输入文本
cy.get('input').type('Hello');     // Cypress
await page.fill('input', 'Hello'); // Playwright

// 下拉选择
cy.get('select').select('Option'); // Cypress
await page.selectOption('select', { label: 'Option' }); // Playwright

  3. 断言验证：

    javascript
    // 元素可见性
cy.get('.element').should('be.visible'); 
await expect(page.locator('.element')).toBeVisible();

// 文本内容
cy.get('h1').should('contain', 'Welcome');
await expect(page.locator('h1')).toContainText('Welcome');

// 网络请求
cy.intercept('POST', '/api/login').as('login');
// ...执行操作...
cy.wait('@login').its('response.statusCode').should('eq', 200);

最佳实践 ​

测试设计原则 ​

  1. 独立测试：每个测试应独立运行，不依赖其他测试状态
  2. 原子操作：每个测试验证单一功能点
  3. 优先关键路径：先覆盖核心业务流程
  4. 幂等设计：多次运行产生相同结果
  5. 可读性优先：测试即文档

高效定位策略 ​

javascript
// 避免使用
cy.get('#root > div > div:nth-child(3) > button') 

// 推荐使用
cy.get('[data-testid="submit-button"]')  // 添加专用测试属性

// Playwright 最佳定位器
await page.getByRole('button', { name: 'Submit' }).click();
await page.getByLabel('Username').fill('testuser');
await page.getByTestId('search-input').type('query');

const fileChooser = await page.waitForEvent('filechooser');

3. 跨域与认证 ​

javascript
// Cypress 跨域处理
Cypress.Commands.add('login', (email, password) => {
  cy.request('POST', '/api/login', { email, password })
    .then(({ body }) => {
      window.localStorage.setItem('authToken', body.token);
    });
});

// Playwright 认证状态复用
const storageState = await page.context().storageState();
// 在配置中复用
use: {
  storageState: 'auth.json'
}

常见测试模式 ​

页面对象模型（POM） ​

javascript
// login.page.js (Cypress)
class LoginPage {
  elements = {
    emailInput: () => cy.get('#email'),
    passwordInput: () => cy.get('#password'),
    submitButton: () => cy.get('button[type="submit"]')
  }

  visit() {
    cy.visit('/login');
  }

  login(email, password) {
    this.elements.emailInput().type(email);
    this.elements.passwordInput().type(password);
    this.elements.submitButton().click();
  }
}

export default new LoginPage();

// 测试中使用
import LoginPage from './login.page';

describe('登录', () => {
  it('应成功登录', () => {
    LoginPage.visit();
    LoginPage.login('user@example.com', 'password');
    cy.url().should('include', '/dashboard');
  });
});

持续集成（CI）配置 ​

GitHub Actions 示例 ​

yaml
name: E2E Tests

on: [push]

jobs:
  cypress-tests:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v3
        
      - name: Install dependencies
        run: npm ci
        
      - name: Run Cypress
        uses: cypress-io/github-action@v5
        with:
          start: npm start
          wait-on: 'http://localhost:3000'
          
  playwright-tests:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v3
        
      - name: Install dependencies
        run: npm ci
        
      - name: Install Playwright
        run: npx playwright install
        
      - name: Run Playwright
        run: npx playwright test
        env:
          BASE_URL: ${{ secrets.APP_URL }}

常见问题解决方案 ​

1. 元素定位不稳定 ​

  • 解决方案：
    • 使用更稳定的定位器（角色、文本）
    • 添加重试逻辑和超时设置
    • 使用 data-testid 属性
    • 等待元素可见后再操作

2. 异步操作处理 ​

javascript
// Cypress 自动等待
cy.get('.loader').should('not.exist');
cy.get('[data-cy="results"]').should('contain', 'Success');

// Playwright 显式等待
await page.waitForSelector('.results', { state: 'visible' });
await page.waitForResponse('/api/data');

3. 测试数据管理 ​

javascript
// 使用夹具（Fixtures）
// cypress/fixtures/users.json
{
  "admin": { "email": "admin@example.com", "password": "secure" }
}

// 测试中使用
cy.fixture('users').then((users) => {
  cy.login(users.admin.email, users.admin.password);
});

// Playwright 工厂函数
async function createTestUser(apiContext) {
  const response = await apiContext.post('/api/users', {
    data: { name: 'Test User' }
  });
  return response.json();
}

最佳实践总结：E2E测试应聚焦核心业务价值而非100%覆盖率。结合Cypress的开发者友好性和Playwright的强大跨浏览器能力，建立关键路径测试防护网。采用页面对象模式提高可维护性，结合CI/CD实现快速反馈，将E2E测试真正融入开发流程，而非最后的质量门禁。
