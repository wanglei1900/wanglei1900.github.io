1. OWASP 核心概念 ​

1.1 OWASP 组织介绍 ​

  • 使命：提升软件安全可见性，成为安全领域的权威社区
  • 核心项目：
    • OWASP Top 10：十大Web应用安全风险
    • ZAP：自动化安全测试工具
    • ASVS：应用安全验证标准
    • Cheat Sheets：安全防护速查表

1.2 安全三要素（CIA） ​

mermaid
graph LR
A[机密性 Confidentiality] -->|数据加密| B[访问控制]
C[完整性 Integrity] -->|数据校验| D[防篡改机制]
E[可用性 Availability] -->|DDoS防护| F[冗余设计]

1.3 安全设计原则 ​

  • 最小权限原则：用户/系统只获必要权限
  • 纵深防御：多层安全防护机制
  • 失效安全：故障时进入安全状态
  • 经济机制：简化安全设计
  • 心理可接受性：安全措施不阻碍正常使用

3.3 安全编码规范 ​

javascript
// 反模式：直接拼接SQL
const query = `SELECT * FROM users WHERE name='${name}'`;

// 安全模式：参数化查询
const query = 'SELECT * FROM users WHERE name=?';
db.execute(query, [name]);

// 反模式：未过滤的HTML输出
element.innerHTML = userInput;

// 安全模式：转义输出
function escapeHtml(unsafe) {
  return unsafe
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&#039;");
}
element.textContent = userInput;

4.2 身份认证安全 ​

多因素认证实现：

javascript
// 基于时间的一次性密码 (TOTP)
const speakeasy = require('speakeasy');
const QRCode = require('qrcode');

// 生成密钥
const secret = speakeasy.generateSecret({ length: 20 });

// 生成二维码
QRCode.toDataURL(secret.otpauth_url, (err, data_url) => {
  console.log('扫描二维码设置MFA:', data_url);
});

// 验证代码
const verified = speakeasy.totp.verify({
  secret: secret.base32,
  encoding: 'base32',
  token: userInputToken
});

4.3 API 安全防护 ​

yaml
# OpenAPI 安全配置示例
openapi: 3.0.0

  securitySchemes:
    BearerAuth:
      type: http
      scheme: bearer
      bearerFormat: JWT
    ApiKeyAuth:
      type: apiKey
      in: header
      name: X-API-KEY
paths:
  /users:
    get:
      security:
        - BearerAuth: []
        - ApiKeyAuth: []
