内存使用生命周期 ​

  1. 分配 - 创建变量、对象、函数等
  2. 使用 - 读取/写入内存
  3. 释放 - 内存不再需要时回收

内存限制 ​

  • 移动设备：通常限制在100-400MB
  • 桌面设备：通常限制在1-4GB
  • 超过限制会导致页面崩溃或强制刷新

  1. 意外全局变量

对象池模式 ​

javascript
class ObjectPool {
  constructor(createFn) {
    this.createFn = createFn;
    this.pool = [];
  }
  
  acquire() {
    return this.pool.length > 0 
      ? this.pool.pop() 
      : this.createFn();
  }
  
  release(obj) {
    // 重置对象状态
    if (obj.reset) obj.reset();
    this.pool.push(obj);
  }
}

// 使用示例
const particlePool = new ObjectPool(() => ({
  x: 0, y: 0, vx: 0, vy: 0,
  reset() {
    this.x = 0; 
    this.y = 0;
    this.vx = 0;
    this.vy = 0;
  }
}));

// 获取粒子
const particle = particlePool.acquire();

// 使用后释放
particlePool.release(particle);

数据分页处理 ​

javascript
async function* paginatedDataFetcher(url, pageSize = 50) {
  let page = 1;
  let hasMore = true;
  
  while (hasMore) {
    const response = await fetch(`${url}?page=${page}&size=${pageSize}`);
    const data = await response.json();
    
    if (data.length < pageSize) {
      hasMore = false;
    }
    
    yield data; // 每次只返回一页数据
    page++;
  }
}

// 使用示例
const dataFetcher = paginatedDataFetcher('/api/large-dataset');

// 按需获取数据
const { value } = await dataFetcher.next();
processData(value);

// 内存监控实现
class MemoryMonitor {
  constructor(threshold = 0.8) {
    this.threshold = threshold;
    this.lastMemory = performance.memory?.usedJSHeapSize || 0;
    this.leakCount = 0;
    this.startMonitoring();
  }
  
  startMonitoring() {
    setInterval(() => {
      const currentMemory = performance.memory?.usedJSHeapSize;
      
      if (!currentMemory) return;
      
      // 检测内存增长
      if (currentMemory > this.lastMemory * 1.5) {
        this.leakCount++;
        
        if (this.leakCount > 3) {
          console.warn('Potential memory leak detected!');
          // 触发内存清理
          this.cleanup();
        }
      } else {
        this.leakCount = 0;
      }
      
      // 检测内存限制
      const limit = performance.memory?.jsHeapSizeLimit || 0;
      if (limit > 0 && currentMemory > limit * this.threshold) {
        console.warn('Memory usage approaching limit!');
        this.freeMemory();
      }
      
      this.lastMemory = currentMemory;
    }, 10000); // 每10秒检查一次
  }
  
  cleanup() {
    // 释放缓存
    // 清理临时对象
  }
  
  freeMemory() {
    // 释放非关键资源
    // 降低功能复杂度
  }
}

// 启动监控
if (performance.memory) {
  new MemoryMonitor();
}

内存管理黄金法则：

  1. 最小分配 - 只分配真正需要的内存
  2. 及时释放 - 不再使用的资源立即释放
  3. 复用优先 - 尽可能复用已有对象
  4. 监控预警 - 实时监控内存使用情况
  5. 渐进优化 - 根据设备能力动态调整内存策略

通过系统化实施这些内存管理技术，可显著提升应用性能，防止崩溃，并为用户提供更流畅的体验。
