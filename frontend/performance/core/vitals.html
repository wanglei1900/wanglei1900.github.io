Web Vitals 监控学习笔记 ​

一、Web Vitals 概述 ​

核心概念 ​

Web Vitals 是 Google 推出的一套关键用户体验指标标准，用于量化网页的用户体验质量。2020年推出，2021年成为Google搜索排名因素。

核心指标演进 ​

时期核心指标组合变化说明
2020-2023LCP + FID + CLS初始核心指标
2024+LCP + INP + CLSFID被INP取代
辅助指标TTFB, FCP, TBT诊断性指标

二、核心指标详解 ​

1. LCP (Largest Contentful Paint) ​

测量视觉加载速度：视口中最大内容元素呈现所需时间

  • 测量目标：≤2.5秒（良好）
  • 测量对象：
    • <img> 元素
    • <image> 在SVG内
    • <video> 海报图
    • 背景图（需预加载）
    • 块级文本节点
javascript
// 手动测量LCP
const observer = new PerformanceObserver((entryList) => {
  const entries = entryList.getEntries();
  const lastEntry = entries[entries.length - 1];
  console.log('LCP:', lastEntry.renderTime || lastEntry.loadTime);
});

observer.observe({type: 'largest-contentful-paint', buffered: true});

2. INP (Interaction to Next Paint) ​

测量交互响应性：从用户交互到页面实际响应的延迟（2024年取代FID）

  • 测量目标：≤200毫秒（良好）
  • 关键改进：考虑整个交互周期（而不仅是首次输入延迟）
javascript
// INP测量示例
const inpTracker = () => {
  let interactionStart = 0;
  
  const listener = (event) => {
    if (event.cancelable) {
      interactionStart = event.timeStamp;
      
      const handler = () => {
        const duration = event.timeStamp - interactionStart;
        console.log(`INP: ${duration}ms`);
        event.target.removeEventListener('pointerup', handler);
      };
      
      event.target.addEventListener('pointerup', handler);
    }
  };
  
  ['mousedown', 'keydown', 'touchstart'].forEach(type => {
    window.addEventListener(type, listener, {capture: true, passive: true});
  });
};

3. CLS (Cumulative Layout Shift) ​

测量视觉稳定性：量化页面生命周期内发生的意外布局偏移总量

  • 测量目标：≤0.1（良好）
  • 计算公式：位移比例 * 影响比例
  • 常见原因：
    • 未指定尺寸的图片/广告
    • 动态注入内容
    • 网络字体导致FOIT/FOUT
javascript
// CLS监控实现
let clsValue = 0;
let clsEntries = [];

const observer = new PerformanceObserver((entryList) => {
  for (const entry of entryList.getEntries()) {
    if (!entry.hadRecentInput) {
      clsEntries.push(entry);
      clsValue += entry.value;
    }
  }
});

observer.observe({type: 'layout-shift', buffered: true});

// 上报最佳实践
addEventListener('visibilitychange', () => {
  if (document.visibilityState === 'hidden') {
    // 上报最终CLS值
    analytics.send('CLS', clsValue);
    
    // 重置计数
    clsValue = 0;
    clsEntries = [];
  }
});

三、辅助性能指标 ​

1. FCP (First Contentful Paint) ​

首次内容绘制：浏览器首次渲染DOM内容的时间

  • 测量目标：≤1.8秒（良好）
  • 与LCP关系：FCP是LCP的前置条件

2. TTFB (Time to First Byte) ​

首字节时间：从请求发出到收到响应第一个字节的时间

  • 测量目标：≤600ms（良好）
  • 核心影响：服务器响应速度、CDN配置

3. TBT (Total Blocking Time) ​

总阻塞时间：FCP到TTI之间所有长任务阻塞时间总和

  • 测量目标：≤200ms（良好）
  • 计算公式：TBT = ∑(任务时长 - 50ms)

2. 自定义监控方案 ​

javascript
class WebVitalsMonitor {
  constructor() {
    this.vitals = {
      LCP: 0,
      INP: 0,
      CLS: 0,
      FCP: 0,
      TTFB: 0
    };
    
    this.init();
  }

  init() {
    this.trackLCP();
    this.trackINP();
    this.trackCLS();
    this.trackFCP();
    this.trackTTFB();
    this.setupVisibilityListener();
  }

  trackTTFB() {
    const { responseStart, requestStart } = performance.timing;
    this.vitals.TTFB = responseStart - requestStart;
  }

  trackFCP() {
    new PerformanceObserver((entryList) => {
      const entries = entryList.getEntriesByName('first-contentful-paint');
      if (entries.length > 0) {
        this.vitals.FCP = entries[0].startTime;
      }
    }).observe({type: 'paint', buffered: true});
  }

  // ...其他跟踪方法

  setupVisibilityListener() {
    document.addEventListener('visibilitychange', () => {
      if (document.visibilityState === 'hidden') {
        this.report();
      }
    });
    
    window.addEventListener('pagehide', this.report.bind(this));
  }

  report() {
    if (navigator.sendBeacon) {
      const data = JSON.stringify(this.vitals);
      navigator.sendBeacon('/api/web-vitals', data);
    } else {
      // 回退方案
      fetch('/api/web-vitals', {
        method: 'POST',
        body: JSON.stringify(this.vitals),
        keepalive: true
      });
    }
  }
}

// 初始化监控
new WebVitalsMonitor();

html
<!-- Web Vitals 状态面板 -->
<div id="vitals-panel" style="position:fixed;bottom:0;right:0;background:#fff;padding:10px;border:1px solid #ccc;z-index:1000;">
  <h3>Web Vitals</h3>
  <table>
    <tr><th>指标</th><th>当前值</th><th>状态</th></tr>
    <tr><td>LCP</td><td id="lcp-value">-</td><td id="lcp-status">-</td></tr>
    <tr><td>INP</td><td id="inp-value">-</td><td id="inp-status">-</td></tr>
    <tr><td>CLS</td><td id="cls-value">-</td><td id="cls-status">-</td></tr>
  </table>

<script>
function updateVitalsPanel(metric) {
  const element = document.getElementById(`${metric.name.toLowerCase()}-value`);
  const status = document.getElementById(`${metric.name.toLowerCase()}-status`);
  
  if (element) {
    element.textContent = metric.value.toFixed(2);
    element.style.color = getColor(metric.value, metric.name);
  }
  
  if (status) {
    status.textContent = getStatus(metric.value, metric.name);
    status.style.color = getColor(metric.value, metric.name);
  }
}

function getColor(value, metric) {
  const thresholds = {
    LCP: [2500, 4000],
    INP: [200, 500],
    CLS: [0.1, 0.25]
  };
  
  if (value <= thresholds[metric][0]) return 'green';
  if (value <= thresholds[metric][1]) return 'orange';
  return 'red';
}

function getStatus(value, metric) {
  const statusMap = {
    LCP: ['良好', '需改进', '较差'],
    INP: ['良好', '需改进', '较差'],
    CLS: ['良好', '需改进', '较差']
  };
  
  const index = value <= thresholds[metric][0] ? 0 : 
                value <= thresholds[metric][1] ? 1 : 2;
  return statusMap[metric][index];
}
</script>

  1. 时间趋势分析：按日/周/月查看指标变化
  2. 页面类型对比：首页 vs 详情页 vs 结算页

INP 优化 ​

  1. 分解长任务：使用 setTimeout 或 requestIdleCallback
  2. 优化事件处理：
    javascript
    // 优化前
document.addEventListener('mousemove', heavyHandler);

// 优化后
document.addEventListener('mousemove', {
  handleEvent(e) {
    if (!this.ticking) {
      requestAnimationFrame(() => {
        heavyHandler(e);
        this.ticking = false;
      });
      this.ticking = true;
    }
  }
});
  3. 内存管理：避免内存泄漏，减少GC暂停
  4. Web Worker：复杂计算移出主线程

CLS 优化 ​

  1. 媒体元素设置尺寸：
    html
    <img src="image.jpg" width="600" height="400" alt="...">
  2. 预留动态内容空间：
    css
    .ad-container {
  width: 300px;
  height: 250px; /* 预留高度 */
}
  3. 字体加载策略：
    css
    @font-face {
  font-family: 'MyFont';
  src: url('myfont.woff2') format('woff2');
  font-display: swap; /* 避免FOIT */
}
  4. transform动画优先：避免触发布局变化
