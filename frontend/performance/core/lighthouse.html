Lighthouse 评分权重 ​

指标权重优秀阈值优化方向
LCP25%≤2.5s资源加载优化
FID25%≤100msJavaScript 优化
CLS25%≤0.1布局稳定性
TBT15%≤200ms主线程优化
Speed Index10%≤3.4s渲染性能

指标测量原理 ​

  • LCP：视口中最大内容元素渲染时间
  • FID：首次用户交互到浏览器响应的延迟
  • CLS：整个生命周期中意外布局偏移的累积分数
  • TBT：FCP 到 TTI 之间阻塞主线程的总时间
  • INP：所有交互的延迟百分位数（取代 FID）

// Web Worker 处理耗时任务
const worker = new Worker('task.js');

// 任务切片
function chunkedTask() {
  const tasks = Array.from({length: 1000});
  
  function processChunk(start) {
    const end = Math.min(start + 50, tasks.length);
    for (let i = start; i < end; i++) {
      // 处理任务
    }
    
    if (end < tasks.length) {
      setTimeout(() => processChunk(end), 0);
    }
  }
  
  processChunk(0);
}

边缘计算优化 ​

javascript
// Cloudflare Workers 示例
addEventListener('fetch', event => {
  event.respondWith(handleRequest(event.request));
});

async function handleRequest(request) {
  // 修改响应头
  const response = await fetch(request);
  const newHeaders = new Headers(response.headers);
  newHeaders.set('Cache-Control', 'public, max-age=86400');
  
  // 优化图片
  if (request.url.includes('.jpg')) {
    return optimizeImage(response);
  }
  
  return new Response(response.body, {
    headers: newHeaders
  });
}

预测预取策略 ​

javascript
// 基于用户行为预测预取
document.addEventListener('mouseover', (e) => {
  const link = e.target.closest('a');
  if (link && isInViewport(link)) {
    const href = link.href;
    // 预取资源
    prefetchResource(href);
  }
});

function prefetchResource(url) {
  if (window.__prefetched) return;
  window.__prefetched = true;
  
  const prefetch = document.createElement('link');
  prefetch.rel = 'prefetch';
  prefetch.href = url;
  prefetch.as = 'document';
  document.head.appendChild(prefetch);
}

Lighthouse 优化黄金法则：

  1. 测量先行 - 优化前建立基准
  2. 优先关键路径 - 聚焦用户核心体验
  3. 渐进增强 - 确保基础功能快速可用
  4. 持续监控 - 性能是持续过程
  5. 真实用户监控 - 结合实验室数据和真实数据

通过系统化实施这些优化策略，可显著提升Lighthouse评分，同时创造更快的用户体验。记住，优化不是一次性任务，而是需要融入开发生命周期的持续过程。
