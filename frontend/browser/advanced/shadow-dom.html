Shadow DOM 封装技术学习笔记 ​

一、Shadow DOM 概述 ​

1.1 什么是 Shadow DOM ​

Shadow DOM 是一种浏览器原生封装技术，允许开发者创建隔离的 DOM 子树，具有以下核心特性：

  • DOM 封装：隐藏组件内部实现细节
  • 样式封装：组件样式不影响外部，外部样式不影响组件
  • 作用域隔离：组件拥有独立的 DOM 和 CSS 作用域
  • 组成模型：通过插槽(slot)实现内容分发

1.2 Shadow DOM 解决的问题 ​

问题传统方式Shadow DOM
CSS 污染全局样式冲突样式作用域隔离
DOM 冲突ID/类名冲突封装 DOM 子树
组件复用需要手动管理自包含组件
第三方集成样式覆盖问题安全边界保护

二、核心概念与术语 ​

2.1 Shadow DOM 结构模型 ​

+-----------------------+
|   宿主元素 (Host)     |
| +-------------------+ |
| |   Shadow Root     | |
| | +---------------+ | |
| | | Shadow Tree   | | |
| | | +-----------+ | | |
| | | | <slot>    | | | |
| | | +-----------+ | | |
| | +---------------+ | |
| +-------------------+ |
|                       |
|    Light DOM 内容     |
|   (用户提供的内容)     |
+-----------------------+

2.2 关键术语 ​

术语描述
Shadow Host挂载 Shadow DOM 的常规 DOM 节点
Shadow RootShadow DOM 的根节点
Shadow TreeShadow Root 下的 DOM 树
Light DOM组件的实际子元素（用户提供）
Slotted Content通过插槽投射到 Shadow DOM 的内容

三、创建与使用 Shadow DOM ​

3.1 基本创建方式 ​

javascript
// 创建宿主元素
const hostElement = document.createElement('div');
hostElement.id = 'host';

// 附加 Shadow Root
const shadowRoot = hostElement.attachShadow({ mode: 'open' });

// 添加内容到 Shadow DOM
shadowRoot.innerHTML = `
  <style>
    :host {
      display: block;
      border: 1px solid #ccc;
      padding: 15px;
    }
    .internal {
      color: blue;
    }
  </style>
  <div class="internal">Shadow DOM 内容</div>
  <slot name="content"></slot>
`;

// 添加到文档
document.body.appendChild(hostElement);

// 添加 Light DOM 内容
const content = document.createElement('div');
content.slot = 'content';
content.textContent = '投射的内容';
hostElement.appendChild(content);

3.2 Shadow Root 模式 ​

模式访问权限特点
open外部可通过 element.shadowRoot 访问推荐模式，允许有限外部访问
closed外部无法访问 Shadow Root更高安全性，但限制灵活性
javascript
// 创建 closed 模式 Shadow DOM
const closedShadow = element.attachShadow({ mode: 'closed' });
console.log(element.shadowRoot); // null (无法访问)

// 内部引用保存
this._shadowRoot = closedShadow;

四、样式封装机制 ​

4.1 样式作用域规则 ​

选择器目标示例
:host宿主元素:host { display: block }
:host()特定状态的宿主:host([disabled]) { opacity: 0.5 }
:host-context()根据宿主祖先:host-context(.dark) { background: #333 }
::slotted()插槽内容::slotted(img) { max-width: 100% }

4.2 样式封装示例 ​

html
<!-- 宿主元素 -->
<custom-card disabled>
  <img src="image.jpg" slot="image">
  <h2 slot="title">卡片标题</h2>
</custom-card>

<!-- Shadow DOM 内部 -->
<style>
  :host {
    display: block;
    border: 1px solid;
  }
  
  :host([disabled]) {
    opacity: 0.6;
    pointer-events: none;
  }
  
  :host-context(.dark-theme) {
    background: #333;
    color: white;
  }
  
  ::slotted(img) {
    border-radius: 50%;
    max-width: 100px;
  }
  
  .card-header {
    font-size: 1.2em;
    color: var(--primary-color, blue);
  }
</style>

<div class="card">
  <div class="card-header">
    <slot name="title">默认标题</slot>
  </div>
  <slot name="image"></slot>
</div>

4.3 使用 CSS 自定义属性 ​

css
/* 组件内部 */
:host {
  background-color: var(--card-bg, #fff);
  border-color: var(--card-border-color, #ddd);

/* 外部全局样式 */

五、插槽(Slot)机制详解 ​

5.1 基本插槽使用 ​

html
<!-- Shadow DOM 模板 -->
<div class="user-card">
  <slot name="avatar">默认头像</slot>
  <div class="info">
    <slot name="name">未命名用户</slot>
    <slot name="email"></slot>
  </div>
</div>

<!-- 使用组件 -->
<user-card>
  <img slot="avatar" src="user.jpg">
  <span slot="name">张三</span>
  <span slot="email">zhangsan@example.com</span>
</user-card>

5.2 插槽高级用法 ​

javascript
// 1. 默认插槽（未命名）
<slot></slot>

// 2. 后备内容（未提供内容时显示）
<slot name="footer">默认页脚</slot>

// 3. 多重插槽（相同名字）
<slot name="extra-info"></slot>
<slot name="extra-info"></slot> <!-- 相同内容会显示两次 -->

// 4. 插槽变化监听
shadowRoot.addEventListener('slotchange', (e) => {
  const slot = e.target;
  if (slot.name === 'content') {
    console.log('内容插槽已更新');
    const nodes = slot.assignedNodes();
    // 处理新节点...
  }
});

六、事件处理与通信 ​

6.1 事件穿透模型 ​

mermaid
graph LR
    A[Shadow DOM 内部] -->|事件| B[Shadow Root]
    B --> C{composed?}
    C -->|true| D[穿透到 Light DOM]
    C -->|false| E[在 Shadow DOM 内处理]
    D --> F[外部 DOM]

6.2 自定义事件配置 ​

javascript
// 创建可穿透事件
const event = new CustomEvent('internal-action', {
  bubbles: true,      // 冒泡通过 DOM
  composed: true,     // 穿透 Shadow DOM 边界
  detail: {           // 传递数据
    element: this,
    timestamp: Date.now()
  }
});

// 分发事件
this.dispatchEvent(event);

6.3 事件重定向 ​

javascript
// 在 Shadow DOM 内重定向事件
shadowRoot.querySelector('button').addEventListener('click', (e) => {
  // 创建新事件并重新分发
  const newEvent = new CustomEvent('card-click', {
    bubbles: true,
    composed: true,
    detail: { originalEvent: e }
  });
  this.dispatchEvent(newEvent);
  
  // 阻止原始事件冒泡
  e.stopPropagation();
});

七、高级封装技巧 ​

7.1 动态样式注入 ​

javascript
class ThemedComponent extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    
    // 创建可复用样式表
    this._styleSheet = new CSSStyleSheet();
    this._styleSheet.replaceSync(`
      :host {
        display: block;
        background: var(--bg-color, white);
      }
    `);
    
    // 添加到 Shadow DOM
    this.shadowRoot.adoptedStyleSheets = [this._styleSheet];
  }
  
  setTheme(theme) {
    // 动态更新样式
    this._styleSheet.replaceSync(`
      :host {
        background: ${theme.background};
        color: ${theme.text};
        padding: ${theme.spacing}px;
      }
    `);
  }
}

7.2 组合式 Shadow DOM ​

javascript
class CompositeComponent extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    
    // 组合多个模板
    const headerTemplate = document.getElementById('header-tpl');
    const bodyTemplate = document.getElementById('body-tpl');
    
    this.shadowRoot.appendChild(headerTemplate.content.cloneNode(true));
    this.shadowRoot.appendChild(bodyTemplate.content.cloneNode(true));
    
    // 添加样式
    const style = document.createElement('style');
    style.textContent = `
      /* 组件样式 */
    `;
    this.shadowRoot.appendChild(style);
  }
}

八、性能优化策略 ​

8.1 Shadow DOM 性能特点 ​

操作性能影响优化建议
初始渲染中等开销延迟加载非关键组件
DOM 更新高效（子树隔离）避免频繁修改 Shadow Root
样式计算高效（作用域限制）减少深层嵌套选择器
事件处理高效（局部冒泡）使用事件委托

8.2 高效渲染模式 ​

javascript
class OptimizedComponent extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    
    // 预定义静态模板
    this.shadowRoot.innerHTML = `
      <div id="container"></div>
    `;
    this.container = this.shadowRoot.getElementById('container');
  }
  
  set data(items) {
    // 高效批量更新（使用 DocumentFragment）
    const fragment = document.createDocumentFragment();
    
    items.forEach(item => {
      const element = document.createElement('div');
      element.textContent = item.name;
      fragment.appendChild(element);
    });
    
    // 单次 DOM 操作
    this.container.innerHTML = '';
    this.container.appendChild(fragment);
  }
}

十、实际应用案例 ​

10.1 可复用模态框组件 ​

javascript
class ModalDialog extends HTMLElement {
  constructor() {
    super();
    this.attachShadow({ mode: 'open' });
    this.shadowRoot.innerHTML = `
      <style>
        :host {
          display: none;
          position: fixed;
          top: 0;
          left: 0;
          width: 100%;
          height: 100%;
          background: rgba(0,0,0,0.5);
          z-index: 1000;
        }
        
        .dialog {
          position: absolute;
          top: 50%;
          left: 50%;
          transform: translate(-50%, -50%);
          background: white;
          padding: 20px;
          border-radius: 8px;
          min-width: 300px;
        }
        
        .close {
          position: absolute;
          top: 10px;
          right: 10px;
          cursor: pointer;
        }
      </style>
      
      <div class="dialog">
        <slot name="header"></slot>
        <slot name="content"></slot>
        <div class="close">×</div>
      </div>
    `;
    
    this.closeButton = this.shadowRoot.querySelector('.close');
    this.closeButton.addEventListener('click', () => this.close());
  }
  
  open() {
    this.style.display = 'block';
    this.dispatchEvent(new Event('open'));
  }
  
  close() {
    this.style.display = 'none';
    this.dispatchEvent(new Event('close'));
  }
}

customElements.define('modal-dialog', ModalDialog);

10.2 主题化按钮组件 ​

javascript
class ThemedButton extends HTMLElement {
  static get observedAttributes() {
    return ['variant', 'size'];
  }

  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });
    
    shadow.innerHTML = `
      <style>
        :host {
          display: inline-block;
        }
        
        button {
          border: none;
          border-radius: 4px;
          padding: 8px 16px;
          cursor: pointer;
          font-family: inherit;
          transition: all 0.2s;
        }
        
        /* 变体样式 */
        :host([variant="primary"]) button {
          background: var(--primary-color, #007bff);
          color: white;
        }
        
        :host([variant="secondary"]) button {
          background: var(--secondary-color, #6c757d);
          color: white;
        }
        
        /* 尺寸样式 */
        :host([size="small"]) button {
          padding: 4px 8px;
          font-size: 0.8rem;
        }
        
        :host([size="large"]) button {
          padding: 12px 24px;
          font-size: 1.2rem;
        }
      </style>
      
      <button>
        <slot></slot>
      </button>
    `;
    
    this.button = shadow.querySelector('button');
  }
  
  attributeChangedCallback(name, oldValue, newValue) {
    if (name === 'variant' || name === 'size') {
      this.button.setAttribute(name, newValue);
    }
  }
}

customElements.define('themed-button', ThemedButton);

十一、最佳实践与常见问题 ​

11.1 最佳实践 ​

  1. 使用 open 模式：除非有特殊安全需求
  2. 合理使用插槽：保持组件灵活性
  3. 响应式设计：使用 CSS 媒体查询和自定义属性
  4. 无障碍访问：添加 ARIA 属性和键盘支持
  5. 性能优化：批量 DOM 操作，避免深层嵌套

11.2 常见问题解决方案 ​

问题解决方案
外部样式无法影响组件使用 CSS 自定义属性或 ::part
组件内事件不冒泡设置 composed: true
插槽内容不显示检查 slot 名称匹配，确保内容有 slot 属性
动态内容不渲染使用 slotchange 事件监听变化
表单元素无法提交在组件内部使用原生表单元素

11.3 未来发展方向 ​

  1. Declarative Shadow DOM (服务端渲染支持)

    html
    <custom-element>
  <template shadowroot="open">
    <style>/* 样式 */</style>
    <slot></slot>
  </template>

</custom-element>

  2. CSS Shadow Parts (增强样式控制)

    css
    custom-element::part(button) {
  background: purple;
}

  3. Custom States (自定义状态伪类)

    css
    :host(:--loading) {
  opacity: 0.6;
}

总结 ​

Shadow DOM 是现代 Web 组件化的核心技术，提供真正的样式和 DOM 封装：

  • 核心优势：作用域隔离、样式封装、组件化
  • 关键机制：宿主元素、影子树、插槽系统
  • 开发模式：组件驱动、封装优先、接口设计
  • 适用场景：UI 组件库、第三方集成、复杂应用模块

学习建议：从简单组件开始实践，逐步掌握插槽使用和样式封装技巧，结合 Custom Elements 创建完整 Web Components。使用开发者工具深入理解 Shadow DOM 的内部结构和事件流，最终构建出可维护、可复用且样式安全的组件体系。
