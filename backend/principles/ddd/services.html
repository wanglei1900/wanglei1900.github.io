领域驱动设计(DDD) - 领域服务 学习笔记 ​

1. 领域服务概述 ​

1.1 定义与定位 ​

领域服务是领域层中的一种特殊组件，用于封装不适合放在实体或值对象中的业务逻辑。

核心特征：

  • 表示领域中的过程或操作，而非事物
  • 无状态，只包含业务逻辑
  • 协调多个领域对象完成复杂操作
  • 属于领域层，不处理技术细节

1.2 领域服务的适用场景 ​

  • 跨多个实体的业务逻辑
  • 需要外部依赖的计算
  • 复杂的业务规则验证
  • 不适合放在单个实体中的操作

2. 领域服务的识别与设计原则 ​

2.1 何时使用领域服务 ​

2.1.1 明显的服务场景 ​

java
// 不适合放在实体中的跨实体操作
public interface OrderCalculationService {
    OrderTotal calculateOrderTotal(Order order, Customer customer, Promotion promotion);
}

// 需要访问外部资源的领域逻辑
public interface TaxCalculationService {
    TaxAmount calculateTax(Order order, TaxJurisdiction jurisdiction);
}

2.1.2 识别模式 ​

  • 操作涉及多个领域对象
  • 操作本身是领域中的重要概念
  • 操作需要访问仓储或其他服务
  • 操作是无状态的

3.1.2 具体实现 ​

java
@Component
public class DefaultInventoryAllocationService implements InventoryAllocationService {
    private final InventoryPolicy inventoryPolicy;
    
    public DefaultInventoryAllocationService(InventoryPolicy inventoryPolicy) {
        this.inventoryPolicy = inventoryPolicy;
    }
    
    @Override
    public AllocationResult allocate(Order order, List<InventoryItem> inventoryItems) {
        Objects.requireNonNull(order, "Order cannot be null");
        Objects.requireNonNull(inventoryItems, "Inventory items cannot be null");
        
        AllocationResult result = new AllocationResult();
        
        for (OrderLine line : order.getOrderLines()) {
            InventoryAllocation lineAllocation = allocateLine(line, inventoryItems);
            result.addAllocation(lineAllocation);
        }
        
        return result;
    }
    
    private InventoryAllocation allocateLine(OrderLine line, List<InventoryItem> inventoryItems) {
        // 复杂的分配逻辑
        List<InventoryItem> availableItems = findAvailableItems(line.getProductId(), inventoryItems);
        return inventoryPolicy.allocate(line, availableItems);
    }
    
    private List<InventoryItem> findAvailableItems(ProductId productId, List<InventoryItem> items) {
        return items.stream()
            .filter(item -> item.getProductId().equals(productId))
            .filter(InventoryItem::isAvailable)
            .collect(Collectors.toList());
    }
}

3.2 复杂业务逻辑服务 ​

3.2.1 订单定价服务 ​

java
public interface OrderPricingService {
    /**
     * 计算订单总价，考虑各种因素
     */
    OrderPrice calculateTotalPrice(Order order, Customer customer, PricingContext context);
}

@Component
public class ComplexOrderPricingService implements OrderPricingService {
    private final ProductPriceService productPriceService;
    private final DiscountCalculationService discountService;
    private final TaxCalculationService taxService;
    
    public ComplexOrderPricingService(
            ProductPriceService productPriceService,
            DiscountCalculationService discountService,
            TaxCalculationService taxService) {
        this.productPriceService = productPriceService;
        this.discountService = discountService;
        this.taxService = taxService;
    }
    
    @Override
    public OrderPrice calculateTotalPrice(Order order, Customer customer, PricingContext context) {
        // 1. 计算基础价格
        Money basePrice = calculateBasePrice(order);
        
        // 2. 应用折扣
        Discount discount = discountService.calculateDiscount(order, customer);
        Money discountedPrice = basePrice.subtract(discount.getAmount());
        
        // 3. 计算税费
        TaxAmount tax = taxService.calculateTax(order, context.getTaxJurisdiction());
        Money finalPrice = discountedPrice.add(tax.getAmount());
        
        return new OrderPrice(basePrice, discount, tax, finalPrice);
    }
    
    private Money calculateBasePrice(Order order) {
        return order.getOrderLines().stream()
            .map(this::calculateLinePrice)
            .reduce(Money.ZERO, Money::add);
    }
    
    private Money calculateLinePrice(OrderLine line) {
        ProductPrice price = productPriceService.getCurrentPrice(line.getProductId());
        return price.getUnitPrice().multiply(line.getQuantity().getValue());
    }
}

3.2.2 库存管理服务 ​

java
public interface InventoryManagementService {
    /**
     * 协调库存分配和预留
     */
    InventoryManagementResult manageOrderInventory(Order order);
    
    /**
     * 处理库存调拨
     */
    TransferResult transferInventory(ProductId productId, Quantity quantity, 
                                   Location from, Location to);
}

@Component
public class DefaultInventoryManagementService implements InventoryManagementService {
    private final InventoryAllocationService allocationService;
    private final InventoryReservationService reservationService;
    private final InventoryRepository inventoryRepository;
    
    @Override
    public InventoryManagementResult manageOrderInventory(Order order) {
        // 1. 查找可用库存
        List<InventoryItem> availableItems = inventoryRepository.findAvailableByProduct(
            order.getProductIds());
        
        // 2. 分配库存
        AllocationResult allocation = allocationService.allocate(order, availableItems);
        
        if (!allocation.isFullyAllocated()) {
            return InventoryManagementResult.failed("Insufficient inventory");
        }
        
        // 3. 预留库存
        ReservationResult reservation = reservationService.reserve(allocation);
        
        // 4. 更新库存状态
        updateInventoryStatus(reservation);
        
        return InventoryManagementResult.success(allocation, reservation);
    }
    
    private void updateInventoryStatus(ReservationResult reservation) {
        reservation.getReservedItems().forEach(item -> {
            item.reserve();
            inventoryRepository.save(item);
        });
    }
}

5.3 异常处理与业务规则 ​

java
public class PaymentProcessingService {
    public PaymentResult processPayment(Order order, PaymentMethod paymentMethod) {
        try {
            validatePayment(order, paymentMethod);
            
            PaymentTransaction transaction = createTransaction(order, paymentMethod);
            PaymentAuthorization auth = authorizePayment(transaction);
            
            if (!auth.isApproved()) {
                return PaymentResult.rejected(auth.getReason());
            }
            
            completePayment(transaction, auth);
            return PaymentResult.approved(transaction);
            
        } catch (PaymentValidationException e) {
            return PaymentResult.invalid(e.getMessage());
        } catch (PaymentGatewayException e) {
            return PaymentResult.error("Payment system temporarily unavailable");
        }
    }
    
    private void validatePayment(Order order, PaymentMethod method) {
        if (order.isPaid()) {
            throw new PaymentValidationException("Order is already paid");
        }
        
        if (method.isExpired()) {
            throw new PaymentValidationException("Payment method has expired");
        }
        
        if (!method.supportsCurrency(order.getCurrency())) {
            throw new PaymentValidationException("Payment method does not support order currency");
        }
    }
}

6. 领域服务与应用服务的区别 ​

6.1 职责对比 ​

方面领域服务应用服务
所属层级领域层应用层
业务逻辑包含核心业务逻辑不包含业务逻辑，只协调
状态无状态无状态

6.2 代码示例对比 ​

6.2.1 领域服务 ​

java
// 领域服务：包含业务逻辑
@Component
public class OrderAllocationService {
    public AllocationResult allocate(Order order, Inventory inventory) {
        // 业务逻辑：如何分配库存
        List<Allocation> allocations = new ArrayList<>();
        
        for (OrderLine line : order.getLines()) {
            Allocation allocation = findBestAllocation(line, inventory);
            if (allocation != null) {
                allocations.add(allocation);
                inventory.allocate(allocation);
            }
        }
        
        return new AllocationResult(allocations);
    }
    
    // 包含复杂的分配算法
    private Allocation findBestAllocation(OrderLine line, Inventory inventory) {
        // 业务规则：优先分配临近过期库存
        return inventory.findAvailableItems(line.getProductId()).stream()
            .filter(item -> item.getQuantity() >= line.getQuantity())
            .min(Comparator.comparing(InventoryItem::getExpiryDate))
            .map(item -> new Allocation(line, item, line.getQuantity()))
            .orElse(null);
    }
}

6.2.2 应用服务 ​

java
// 应用服务：协调工作，不包含业务逻辑
@Service
@Transactional
public class OrderApplicationService {
    private final OrderRepository orderRepository;
    private final InventoryRepository inventoryRepository;
    private final OrderAllocationService allocationService;
    private final NotificationService notificationService;
    
    public void allocateOrder(String orderId) {
        // 1. 获取数据
        Order order = orderRepository.findById(orderId)
            .orElseThrow(() -> new OrderNotFoundException(orderId));
        Inventory inventory = inventoryRepository.findByWarehouse(order.getWarehouseId());
        
        // 2. 调用领域服务执行业务逻辑
        AllocationResult result = allocationService.allocate(order, inventory);
        
        // 3. 保存状态
        orderRepository.save(order);
        inventoryRepository.save(inventory);
        
        // 4. 通知相关方
        if (result.isFullyAllocated()) {
            notificationService.notifyOrderReadyForFulfillment(order);
        } else {
            notificationService.notifyPartialAllocation(order, result);
        }
    }
}

// 策略接口
public interface DiscountStrategy {
    Discount calculateDiscount(Order order, Customer customer);
}

// 具体策略
@Component
public class VolumeDiscountStrategy implements DiscountStrategy {
    @Override
    public Discount calculateDiscount(Order order, Customer customer) {
        if (order.getTotalAmount().isGreaterThan(Money.of(1000))) {
            return new Discount(order.getTotalAmount().percentage(10));
        }
        return Discount.NONE;
    }
}

@Component
public class LoyaltyDiscountStrategy implements DiscountStrategy {
    @Override
    public Discount calculateDiscount(Order order, Customer customer) {
        if (customer.getLoyaltyTier().isAtLeast(LoyaltyTier.GOLD)) {
            return new Discount(order.getTotalAmount().percentage(5));
        }
        return Discount.NONE;
    }
}

// 使用策略的领域服务
@Component
public class DiscountCalculationService {
    private final List<DiscountStrategy> strategies;
    
    public DiscountCalculationService(List<DiscountStrategy> strategies) {
        this.strategies = strategies;
    }
    
    public Discount calculateBestDiscount(Order order, Customer customer) {
        return strategies.stream()
            .map(strategy -> strategy.calculateDiscount(order, customer))
            .max(Comparator.comparing(Discount::getAmount))
            .orElse(Discount.NONE);
    }
}

public class OrderService {
    public void updateOrderStatus(String orderId, String status) {
        Order order = repository.findById(orderId);
        order.setStatus(status);  // 应该由Order实体自己处理状态转换
        repository.save(order);
    }
}

// 正确做法：业务逻辑在实体中
public class Order {
    public void markAsShipped() {
        if (!canBeShipped()) {
            throw new IllegalStateException("Order cannot be shipped");
        }
        this.status = OrderStatus.SHIPPED;
        this.shippedAt = Instant.now();
    }
}

10. 总结 ​

10.1 核心要点 ​

  1. 领域服务封装不适合放在实体中的业务逻辑
  2. 保持无状态和单一职责
  3. 使用明确的领域术语命名
  4. 与实体和值对象紧密协作
  5. 区分领域服务与应用服务的职责

10.2 设计检查清单 ​

  • [ ] 操作是否涉及多个领域对象？
  • [ ] 操作是否是领域中的重要概念？
  • [ ] 服务是否无状态？
  • [ ] 命名是否明确表达业务意图？
  • [ ] 是否避免了贫血设计？
  • [ ] 依赖是否通过接口注入？
  • [ ] 是否易于测试？

通过正确使用领域服务，可以保持领域模型的纯净性，将复杂的业务流程封装在合适的组件中，提高代码的可维护性和可测试性。
