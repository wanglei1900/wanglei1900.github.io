可观测性、性能分析与内存分析学习笔记 ​

1. 可观测性基础 ​

1.1 可观测性概念 ​

可观测性是指通过系统外部输出理解系统内部状态的能力，基于三大支柱：

  • 指标 (Metrics)
  • 日志 (Logs)
  • 追踪 (Traces)
mermaid
graph TB
    A[可观测性] --> B[指标 Metrics]
    A --> C[日志 Logs]
    A --> D[追踪 Traces]
    
    B --> B1[时序数据]
    B --> B2[聚合分析]
    
    C --> C1[结构化日志]
    C --> C2[日志级别]
    
    D --> D1[分布式追踪]
    D --> D2[调用链分析]

1.2 三大支柱详解 ​

1.2.1 指标 (Metrics) ​

  • 计数器 (Counter): 单调递增的数值
  • 计量器 (Gauge): 可上下波动的数值
  • 直方图 (Histogram): 样本观测，计算可配置桶中的统计
  • 摘要 (Summary): 类似直方图，但计算分位数

1.2.2 日志 (Logs) ​

  • 结构化日志 vs 非结构化日志
  • 日志级别: DEBUG, INFO, WARN, ERROR, FATAL
  • 日志聚合与分析工具

1.2.3 追踪 (Traces) ​

  • 分布式请求跟踪
  • Span: 操作的基本单位
  • Trace: 相关的Span集合

2.2 CPU性能分析 ​

2.2.1 分析方法 ​

  • 采样分析: 周期性采集调用栈
  • 插桩分析: 在特定点插入测量代码
  • 事件基础分析: 基于特定事件进行分析

2.2.2 关键指标 ​

  • CPU使用率
  • 上下文切换次数
  • 系统调用次数
  • 函数调用频率

3.3 内存泄漏检测 ​

3.3.1 常见泄漏模式 ​

  1. 静态集合类持有引用
  2. 未关闭的资源
  3. 监听器未注销
  4. 内部类持有外部类引用
  5. 缓存无限增长

3.3.2 检测方法 ​

java
// Java示例：弱引用检测内存泄漏
public class MemoryLeakDetector {
    private static final Map<Object, WeakReference<Object>> LEAK_MAP = 
        new WeakHashMap<>();
    
    public static void trackObject(Object obj, String description) {
        LEAK_MAP.put(obj, new WeakReference<>(obj));
    }
}

4.3.2 内存优化 ​

java
// 示例：对象池减少内存分配
public class ObjectPool<T> {
    private final Queue<T> pool;
    private final Supplier<T> creator;
    
    public ObjectPool(int size, Supplier<T> creator) {
        this.pool = new LinkedList<>();
        this.creator = creator;
        for (int i = 0; i < size; i++) {
            pool.offer(creator.get());
        }
    }
    
    public T borrow() {
        return pool.isEmpty() ? creator.get() : pool.poll();
    }
    
    public void returnObject(T obj) {
        pool.offer(obj);
    }
}
