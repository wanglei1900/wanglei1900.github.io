可观测性 - 链路追踪 - 上下文传播 学习笔记 ​

1. 可观测性基础 ​

1.1 可观测性三大支柱 ​

可观测性 = 指标(Metrics) + 日志(Logs) + 追踪(Traces)

1.2 可观测性 vs 监控 ​

  • 监控：已知问题的检测和告警
  • 可观测性：未知问题的探索和理解

2. 链路追踪基础 ​

2.1 核心概念 ​

Trace（追踪） ​

  • 一个完整的请求处理过程
  • 包含多个Span的有向无环图
  • 全局唯一的Trace ID

Span（跨度） ​

  • 单个工作单元的执行信息
  • 包含：
    • 开始时间和持续时间
    • 操作名称
    • 标签和日志
    • 父子关系

    B --> D[Span: Cache Lookup]

3. 上下文传播 ​

3.1 什么是上下文传播 ​

在分布式系统中传递追踪上下文信息，确保所有相关服务都能关联到同一个Trace。

3.2 传播模式 ​

3.2.1 W3C Trace Context ​

http
Traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
Tracestate: vendor1=value1,vendor2=value2

3.2.2 B3 Propagation ​

http
X-B3-TraceId: 4bf92f3577b34da6a3ce929d0e0e4736

X-B3-ParentSpanId: 1234567890abcdef

3.3 传播流程 ​

mermaid
sequenceDiagram
    participant Client
    participant ServiceA
    participant ServiceB
    participant ServiceC
    
    Client->>ServiceA: HTTP Request + Trace Context

4. 实现模式 ​

4.1 自动注入（推荐） ​

java
// Java示例 - 使用OpenTelemetry自动注入
@RestController
public class UserController {
    
    @Autowired
    private Tracer tracer;
    
    @GetMapping("/users/{id}")
    public User getUser(@PathVariable String id) {
        Span span = tracer.spanBuilder("getUser")
                         .startSpan();
        try (Scope scope = span.makeCurrent()) {
            // 业务逻辑会自动关联到当前span
            return userService.findUser(id);
        } finally {
            span.end();
        }
    }
}

4.2 手动传播 ​

python
# Python示例 - 手动传播上下文
from opentelemetry import trace
from opentelemetry.propagate import inject, extract

def handle_request(request_headers):
    # 提取上下文
    context = extract(request_headers)
    
    tracer = trace.get_tracer(__name__)
    with tracer.start_as_current_span("process_order", context=context) as span:
        span.set_attribute("order.id", "12345")
        
        # 调用下游服务时注入上下文
        headers = {}
        inject(headers)
        
        # 发送HTTP请求
        response = requests.post(
            "http://inventory-service/update",
            headers=headers,
            json={"order_id": "12345"}
        )

4.3 异步上下文传播 ​

javascript
// Node.js示例 - 异步上下文传播
const { context, trace } = require('@opentelemetry/api');

async function processOrder(orderId) {
  const tracer = trace.getTracer('order-service');
  const span = tracer.startSpan('processOrder');
  
  return await context.with(trace.setSpan(context.active(), span), async () => {
    try {
      // 所有异步操作都会保持上下文
      await validateOrder(orderId);
      await updateInventory(orderId);
      await sendNotification(orderId);
      
      span.setStatus({ code: trace.SpanStatusCode.OK });
    } catch (error) {
      span.setStatus({ code: trace.SpanStatusCode.ERROR });
      span.recordException(error);
      throw error;
    } finally {
      span.end();
    }
  });
}

5.2 采样配置示例 ​

yaml
# Jaeger采样配置
sampling:
  default_strategy:
    type: probabilistic
    param: 0.01  # 1%采样率
  per_operation_strategies:
    - operation: /api/health
      type: const
      param: 0    # 不采样健康检查
    - operation: /api/payment
      type: probabilistic
      param: 1.0  # 100%采样支付相关

6. 最佳实践 ​

6.1 命名规范 ​

java
// 好的命名
spanBuilder("http.request")
    .setAttribute("http.method", "GET")
    .setAttribute("http.route", "/users/{id}")

// 避免的命名
spanBuilder("doStuff")  // 太模糊
spanBuilder("method1")  // 无意义

6.2 标签设计原则 ​

python
# 结构化标签
span.set_attributes({
    "http.method": "POST",
    "http.status_code": 201,
    "db.system": "postgresql",
    "db.operation": "INSERT",
    "user.id": user_id,
    "order.amount": 99.99
})

# 避免敏感信息
span.set_attribute("user.email", "xxx")  # ❌ 避免
span.set_attribute("user.id", "12345")   # ✅ 安全

6.3 错误处理 ​

go
// Go示例 - 正确的错误记录
func processRequest(ctx context.Context) error {
    tracer := otel.Tracer("service-name")
    ctx, span := tracer.Start(ctx, "processRequest")
    defer span.End()
    
    err := businessLogic(ctx)
    if err != nil {
        span.RecordError(err)
        span.SetStatus(codes.Error, "processing failed")
        return err
    }
    
    span.SetStatus(codes.Ok, "success")
    return nil
}

工具类型特点
