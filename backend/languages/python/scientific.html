SymPy：符号计算 ​

python
from sympy import symbols, diff, integrate, solve, Eq

x, y = symbols('x y')
expr = x**2 + 2*x + 1

# 符号运算
derivative = diff(expr, x)             # 微分: 2*x + 2
integral = integrate(expr, (x, 0, 1))  # 积分: 4/3
solutions = solve(Eq(expr, 0), x)      # 解方程: [-1]

环境管理 ​

虚拟环境 ​

bash
# 创建环境
python -m venv myenv

# 激活环境
# Linux/macOS
source myenv/bin/activate

# Windows
myenv\Scripts\activate

# 安装包
pip install numpy pandas matplotlib

# 导出环境
pip freeze > requirements.txt

# 恢复环境
pip install -r requirements.txt

Conda环境 ​

bash
# 创建环境
conda create --name scipy_env python=3.9

# 激活环境
conda activate scipy_env

# 安装科学计算包
conda install numpy scipy pandas matplotlib jupyter

# 导出环境
conda env export > environment.yml

# 恢复环境
conda env create -f environment.yml
