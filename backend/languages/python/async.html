Python 异步编程学习笔记 ​

一、异步编程基础概念 ​

1.1 同步 vs 异步 ​

特性同步异步
执行方式顺序执行并发执行
阻塞情况I/O操作会阻塞整个程序I/O操作不会阻塞程序执行
资源占用线程/进程开销大单线程处理多个任务
适用场景CPU密集型任务I/O密集型任务
编程复杂度相对简单较复杂

1.2 Python 异步编程演进 ​

  • Python 3.4: asyncio 引入标准库
  • Python 3.5: async/await 关键字
  • Python 3.7: asyncio.run() 简化入口
  • Python 3.9: asyncio.to_thread() 线程集成
  • Python 3.11: 异步任务组和异常组

1.3 核心概念 ​

  • 协程(Coroutine): 可暂停和恢复的函数
  • 事件循环(Event Loop): 调度和执行协程的核心
  • Future: 表示异步操作的最终结果
  • Task: 对协程的封装，用于调度执行

二、asyncio 核心组件 ​

2.1 事件循环 (Event Loop) ​

python
import asyncio

# 获取事件循环
loop = asyncio.get_event_loop()

# 运行协程直到完成
loop.run_until_complete(main_coroutine())

# 关闭事件循环
loop.close()

# Python 3.7+ 简化写法
asyncio.run(main_coroutine())

2.2 协程定义与执行 ​

python
import asyncio

# 定义协程
async def hello_world():
    print("Hello")
    await asyncio.sleep(1)  # 非阻塞等待
    print("World")

# 执行协程
asyncio.run(hello_world())

2.3 Future 和 Task ​

python
async def main():
    # 创建任务
    task = asyncio.create_task(my_coroutine())
    
    # 等待任务完成
    await task
    
    # 获取结果
    result = task.result()
    
    # 创建Future
    future = asyncio.Future()
    
    # 设置结果
    future.set_result("Done")
    
    # 等待Future完成
    result = await future

三、异步控制流 ​

3.1 并发执行多个任务 ​

python
async def main():
    # 同时运行多个任务
    task1 = asyncio.create_task(fetch_data(url1))
    task2 = asyncio.create_task(fetch_data(url2))
    
    # 等待所有任务完成
    results = await asyncio.gather(task1, task2)
    print(results)

3.2 任务管理 ​

python
async def main():
    # 创建任务组 (Python 3.11+)
    async with asyncio.TaskGroup() as tg:
        task1 = tg.create_task(fetch_data(url1))
        task2 = tg.create_task(fetch_data(url2))
    
    # 所有任务完成后继续执行
    print(f"Results: {task1.result()}, {task2.result()}")

3.3 超时控制 ​

python
async def main():
    try:
        # 设置超时限制
        async with asyncio.timeout(5.0):
            await long_running_operation()
    except TimeoutError:

3.4 等待第一个完成 ​

python
async def main():
    # 创建多个任务
    tasks = [asyncio.create_task(fetch(url)) for url in urls]
    
    # 等待第一个完成的任务
    done, pending = await asyncio.wait(tasks, return_when=asyncio.FIRST_COMPLETED)
    
    # 处理已完成的任务
    for task in done:
        print(f"Completed: {task.result()}")
    
    # 取消剩余任务
    for task in pending:
        task.cancel()

五、同步与互斥 ​

5.1 异步锁 ​

python
async def update_shared_data(lock, data):
    async with lock:  # 获取锁
        # 临界区代码
        data['counter'] += 1
        await asyncio.sleep(0.1)

async def main():
    lock = asyncio.Lock()
    data = {'counter': 0}
    
    tasks = [update_shared_data(lock, data) for _ in range(10)]
    await asyncio.gather(*tasks)
    
    print(f"Final counter: {data['counter']}")  # 应为10

5.2 信号量 (控制并发数) ​

python
async def limited_resource(semaphore, resource_id):
    async with semaphore:
        print(f"Accessing resource {resource_id}")
        await asyncio.sleep(1)
        print(f"Released resource {resource_id}")

async def main():
    semaphore = asyncio.Semaphore(3)  # 同时最多3个访问
    
    tasks = [limited_resource(semaphore, i) for i in range(10)]
    await asyncio.gather(*tasks)

6.2 异步上下文管理器 ​

python
class AsyncConnection:
    async def __aenter__(self):
        print("Connecting...")
        await asyncio.sleep(0.5)
        return self
    
    async def __aexit__(self, exc_type, exc, tb):
        print("Disconnecting...")
        await asyncio.sleep(0.2)
    
    async def query(self):
        print("Executing query...")
        await asyncio.sleep(1)
        return "result"

async def main():
    async with AsyncConnection() as conn:
        result = await conn.query()
        print(f"Query result: {result}")

6.3 异步迭代器 ​

python
class AsyncRange:
    def __init__(self, start, stop):
        self.start = start
        self.stop = stop
    
    def __aiter__(self):
        self.current = self.start
        return self
    
    async def __anext__(self):
        if self.current >= self.stop:
            raise StopAsyncIteration
        value = self.current
        self.current += 1
        await asyncio.sleep(0.1)
        return value

async def main():
    async for i in AsyncRange(1, 6):
        print(i)  # 输出 1,2,3,4,5

7.3 常见性能问题及解决方案 ​

问题原因解决方案
事件循环阻塞CPU密集型任务占用事件循环使用loop.run_in_executor()
任务饥饿某些任务长时间占用CPU在适当位置添加await asyncio.sleep(0)
内存泄漏未正确取消任务使用asyncio.create_task()和任务组
过度并发导致资源耗尽同时创建过多任务使用信号量限制并发数

八、与多线程/多进程集成 ​

8.1 在异步中运行同步代码 ​

python
import asyncio
import time

def blocking_io():
    print("Start blocking I/O")
    time.sleep(2)  # 模拟阻塞I/O
    print("End blocking I/O")
    return "result"

async def main():
    # 在单独线程中运行阻塞函数
    result = await asyncio.to_thread(blocking_io)
    print(f"Result: {result}")
    
    # 在进程池中运行CPU密集型任务
    loop = asyncio.get_running_loop()
    result = await loop.run_in_executor(
        None,  # 使用默认执行器
        cpu_intensive_task, 
        arg1, arg2
    )

8.2 在同步代码中调用异步函数 ​

def sync_wrapper():

# 在同步环境中调用
result = sync_wrapper()

九、最佳实践 ​

9.1 设计原则 ​

  1. 避免阻塞调用：在异步代码中不使用同步I/O
  2. 合理控制并发：使用信号量限制资源使用
  3. 任务生命周期管理：确保任务被正确取消
  4. 错误处理：为每个任务添加异常处理
  5. 资源清理：使用异步上下文管理器

9.2 常见错误处理模式 ​

python
async def safe_task(task_func):
    try:
        return await task_func()
    except Exception as e:
        print(f"Task failed: {e}")
        # 执行清理操作
        return None

async def main():
    tasks = [safe_task(fetch_data) for _ in range(5)]
    results = await asyncio.gather(*tasks, return_exceptions=True)
    
    for result in results:
        if isinstance(result, Exception):
            print(f"Error occurred: {result}")

十一、架构模式 ​

11.1 生产者-消费者模式 ​

python
async def producer(queue):
    for i in range(5):
        await queue.put(i)
        await asyncio.sleep(0.1)
    await queue.put(None)  # 结束信号

async def consumer(queue):
    while True:
        item = await queue.get()
        if item is None:
            break
        print(f"Consumed: {item}")
        queue.task_done()

async def main():
    queue = asyncio.Queue(maxsize=3)
    prod = asyncio.create_task(producer(queue))
    cons = asyncio.create_task(consumer(queue))
    
    await prod
    await queue.join()  # 等待所有任务完成
    await cons

11.2 发布-订阅模式 ​

python
from asyncio import Event, Queue

class PubSub:
    def __init__(self):
        self.subscribers = {}
        self.lock = asyncio.Lock()
    
    async def subscribe(self, channel):
        async with self.lock:
            if channel not in self.subscribers:
                self.subscribers[channel] = []
            queue = Queue()
            self.subscribers[channel].append(queue)
            return queue
    
    async def publish(self, channel, message):
        async with self.lock:
            if channel in self.subscribers:
                for queue in self.subscribers[channel]:
                    await queue.put(message)

重要提示：异步编程适用于I/O密集型应用，对于CPU密集型任务应考虑结合多进程使用。始终遵循"不阻塞事件循环"原则，合理管理任务生命周期，并使用适当的错误处理机制。
