1. 并发基础 ​

1.1 进程与线程 ​

  • 进程：操作系统资源分配的基本单位
  • 线程：CPU调度的基本单位，共享进程资源
  • 多线程优势：提高资源利用率、响应速度、简化异步处理

1.2 Java内存模型(JMM) ​

mermaid
graph LR
    A[主内存] --> B[线程A工作内存]
    A --> C[线程B工作内存]
    B -->|同步| A
    C -->|同步| A

  • 三大特性：

    • 原子性：操作不可中断
    • 可见性：修改后其他线程立即可见
    • 有序性：指令重排序保证最终一致性

  • Happens-Before原则：

    • 程序顺序规则
    • 锁规则
    • volatile变量规则
    • 线程启动规则
    • 传递性规则

2. 线程管理 ​

2.1 线程创建 ​

java
// 方式1：继承Thread类
class MyThread extends Thread {
    public void run() {
        // 线程执行逻辑
    }
}
new MyThread().start();

// 方式2：实现Runnable接口
Runnable task = () -> { /* 执行逻辑 */ };
new Thread(task).start();

// 方式3：实现Callable接口
Callable<Integer> callableTask = () -> {
    // 执行逻辑
    return 42;
};
FutureTask<Integer> futureTask = new FutureTask<>(callableTask);
new Thread(futureTask).start();

2.2 线程状态 ​

mermaid
stateDiagram-v2
    [*] --> NEW
    NEW --> RUNNABLE: start()
    RUNNABLE --> BLOCKED: 等待锁
    RUNNABLE --> WAITING: wait()/join()
    RUNNABLE --> TIMED_WAITING: sleep(n)
    RUNNABLE --> TERMINATED: 执行完成
    BLOCKED --> RUNNABLE: 获取锁
    WAITING --> RUNNABLE: notify()/notifyAll()
    TIMED_WAITING --> RUNNABLE: 超时/唤醒

2.3 线程控制 ​

  • sleep()：线程休眠，不释放锁
  • yield()：让出CPU执行权
  • join()：等待线程终止
  • interrupt()：中断线程（协作式）
  • setDaemon(true)：设置为守护线程

3. 同步机制 ​

3.1 synchronized ​

java
// 同步方法
public synchronized void syncMethod() { 
    // 临界区 
}

// 同步代码块
public void method() {
    synchronized(lockObject) {
        // 临界区
    }
}

3.2 Lock接口 ​

java
Lock lock = new ReentrantLock();

lock.lock();  // 手动加锁
try {
    // 临界区
} finally {
    lock.unlock();  // 必须在finally中释放
}

3.3 volatile关键字 ​

  • 保证可见性
  • 禁止指令重排序
  • 不保证原子性（如count++操作）

3.4 线程通信 ​

java
// wait/notify 机制
synchronized(lock) {
    while(conditionNotMet) {
        lock.wait();
    }
    // 执行业务逻辑
    lock.notifyAll();
}

3.5 Condition接口 ​

java
Lock lock = new ReentrantLock();
Condition condition = lock.newCondition();

lock.lock();
try {
    condition.await();      // 等待
    condition.signal();     // 唤醒单个
    condition.signalAll();  // 唤醒所有
} finally {
    lock.unlock();
}

4. 并发工具类 ​

4.1 CountDownLatch ​

java
CountDownLatch latch = new CountDownLatch(3);

// 工作线程
new Thread(() -> {
    // 执行任务
    latch.countDown();
}).start();

// 主线程等待
latch.await();  // 阻塞直到计数器归零

4.2 CyclicBarrier ​

java
CyclicBarrier barrier = new CyclicBarrier(3, () -> {
    // 所有线程到达后执行的回调
});

new Thread(() -> {
    // 执行任务
    barrier.await();  // 等待其他线程
}).start();

4.3 Semaphore ​

java
Semaphore semaphore = new Semaphore(5); // 允许5个并发

semaphore.acquire();  // 获取许可
try {
    // 访问共享资源
} finally {
    semaphore.release();  // 释放许可
}

4.4 Exchanger ​

java
Exchanger<String> exchanger = new Exchanger<>();

new Thread(() -> {
    String data = "Thread1 Data";
    String received = exchanger.exchange(data);
}).start();

new Thread(() -> {
    String data = "Thread2 Data";
    String received = exchanger.exchange(data);

6. 线程池 ​

6.1 核心接口 ​

  • Executor：执行任务的简单接口
  • ExecutorService：扩展了Executor的生命周期管理
  • ScheduledExecutorService：支持定时任务

6.2 ThreadPoolExecutor参数 ​

java
new ThreadPoolExecutor(
    corePoolSize,     // 核心线程数
    maximumPoolSize,  // 最大线程数
    keepAliveTime,    // 空闲线程存活时间
    TimeUnit,         // 时间单位
    workQueue,        // 任务队列
    threadFactory,    // 线程工厂
    handler           // 拒绝策略
);

6.3 拒绝策略 ​

  • AbortPolicy：默认策略，抛出RejectedExecutionException
  • CallerRunsPolicy：由调用线程执行该任务
  • DiscardPolicy：直接丢弃任务
  • DiscardOldestPolicy：丢弃队列最前面的任务

6.4 Executors工厂方法 ​

java
// 固定大小线程池
ExecutorService fixedPool = Executors.newFixedThreadPool(5);

// 单线程池
ExecutorService singleThreadPool = Executors.newSingleThreadExecutor();

// 可缓存线程池
ExecutorService cachedPool = Executors.newCachedThreadPool();

8. Fork/Join框架 ​

8.1 核心组件 ​

  • ForkJoinPool：特殊线程池

  • RecursiveAction：无返回值任务
  • RecursiveTask：有返回值任务

8.2 工作窃取算法 ​

mermaid
graph LR
    A[线程1任务队列] --> B[线程1]
    C[线程2任务队列] --> D[线程2]
    D -->|窃取任务| A

8.3 示例：并行计算斐波那契数列 ​

java
class FibonacciTask extends RecursiveTask<Integer> {
    final int n;
    FibonacciTask(int n) { this.n = n; }
    
    protected Integer compute() {
        if (n <= 1) return n;
        FibonacciTask f1 = new FibonacciTask(n - 1);
        f1.fork();
        FibonacciTask f2 = new FibonacciTask(n - 2);
        return f2.compute() + f1.join();
    }
}

// 使用
ForkJoinPool pool = new ForkJoinPool();
FibonacciTask task = new FibonacciTask(10);
int result = pool.invoke(task);

9. 最佳实践 ​

9.1 并发设计原则 ​

  1. 优先使用并发工具类：避免直接使用底层同步原语
  2. 缩小同步范围：减少锁持有时间
  3. 使用不可变对象：天然线程安全
  4. 线程封闭：ThreadLocal或局部变量
  5. 避免死锁：按固定顺序获取锁

9.2 性能调优 ​

  • 减少上下文切换：合理设置线程数
  • 减少锁竞争：锁分解、锁分段
  • 使用读写锁：ReentrantReadWriteLock
  • 无锁编程：CAS操作

9.3 常见问题排查 ​

  1. 死锁检测：

    • jstack查看线程状态
    • 使用ThreadMXBean检测死锁

  2. 线程泄漏：

    • 确保线程池正确关闭
    • 检查未处理的异常

  3. 资源竞争：

    • 使用并发集合替代同步集合
    • 避免热点域竞争

9.4 Java并发演进 ​

  • Java 5：java.util.concurrent包
  • Java 7：Fork/Join框架
  • Java 8：CompletableFuture，并行流
  • Java 9：响应式流API
  • Java 21：虚拟线程（预览）

提示：在实际开发中，优先考虑使用高级并发工具而非直接操作线程，遵循"不要重复造轮子"原则，合理利用JDK提供的并发组件。
