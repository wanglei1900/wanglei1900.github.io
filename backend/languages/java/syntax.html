Java 基础语法学习笔记 ​

一、Java 程序结构 ​

Hello World 程序 ​

java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

程序结构解析 ​

  • public class HelloWorld：定义一个公共类，类名必须与文件名一致
  • public static void main(String[] args)：主方法，程序入口点
  • System.out.println()：标准输出方法

二、基本语法规则 ​

  1. 大小写敏感：Hello 和 hello 是不同的标识符
  2. 类名：采用大驼峰命名法（如 MyFirstClass）
  3. 方法名：采用小驼峰命名法（如 myFirstMethod()）
  4. 源文件名：必须与公共类名完全匹配（.java 扩展名）
  5. 主方法：public static void main(String[] args) 是固定入口格式

六、控制流语句 ​

条件语句 ​

java
// if-else
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");

循环语句 ​

java

八、方法 ​

方法定义 ​

java
// 无返回值方法
public static void greet(String name) {
    System.out.println("Hello, " + name + "!");
}

// 有返回值方法
public static int add(int a, int b) {
    return a + b;
}

// 方法重载（同名不同参）
public static int add(int a, int b, int c) {
    return a + b + c;
}

方法调用 ​

java
greet("Alice"); // 输出: Hello, Alice!
int result = add(5, 3); // result = 8
int sum = add(1, 2, 3); // sum = 6

九、面向对象基础 ​

类与对象 ​

java
// 定义类
public class Car {
    // 字段（属性）
    String brand;
    String color;
    int maxSpeed;
    
    // 构造方法
    public Car(String brand, String color, int maxSpeed) {
        this.brand = brand;
        this.color = color;
        this.maxSpeed = maxSpeed;
    }
    
    // 方法
    public void drive() {
        System.out.println(color + " " + brand + " is driving at " + maxSpeed + " km/h");
    }
}

// 创建对象
public class Main {
    public static void main(String[] args) {
        Car myCar = new Car("Toyota", "Red", 200);
        myCar.drive(); // 输出: Red Toyota is driving at 200 km/h
    }
}

封装 ​

java
public class Person {
    private String name; // 私有字段
    private int age;
    
    // Getter方法
    public String getName() {
        return name;

    // Setter方法
    public void setName(String name) {
        this.name = name;
    }
    
    public int getAge() {
        return age;
    }
    
    public void setAge(int age) {
        if (age > 0) {
            this.age = age;
        }
    }
}

十一、异常处理 ​

java
try {
    // 可能抛出异常的代码
    int result = 10 / 0;
} catch (ArithmeticException e) {
    // 处理特定异常
    System.out.println("除以零错误: " + e.getMessage());
} catch (Exception e) {
    // 处理其他异常
    System.out.println("发生错误: " + e);
} finally {
    // 无论是否发生异常都会执行的代码
    System.out.println("执行清理工作");
}

十四、代码规范 ​

  1. 缩进：使用4个空格缩进
  2. 大括号：左大括号与声明语句同行，右大括号单独一行
  3. 命名：
    • 类名：大驼峰式 (MyClassName)
    • 方法名/变量名：小驼峰式 (myMethodName)
    • 常量名：全大写，下划线分隔 (MAX_VALUE)
  4. 每行只声明一个变量
  5. 避免魔术数字：使用常量代替字面值
  6. 一行代码不超过80个字符
