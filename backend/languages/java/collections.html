Java集合框架学习笔记 ​

一、集合框架概述 ​

Java集合框架（Java Collections Framework, JCF）是一套用于存储和操作数据集合的标准接口和实现类库，位于java.util包中。

主要优点： ​

  • 标准化架构：统一的接口和实现
  • 高性能：针对不同场景优化的实现
  • 可扩展性：易于扩展和自定义
  • 降低学习成本：统一的API设计

核心接口层次： ​

Collection
├── List
├── Set
│   ├── SortedSet
└── Queue
    └── Deque

Map
└── SortedMap

二、Collection接口 ​

所有集合类的基本接口，定义通用方法：

java
boolean add(E e);
boolean remove(Object o);
boolean contains(Object o);
int size();
boolean isEmpty();
Iterator<E> iterator();
// ...其他方法

1. List接口 ​

特点：有序集合（插入顺序），允许重复元素，允许null值

实现类底层结构线程安全特点
ArrayList动态数组不安全随机访问快，增删慢
LinkedList双向链表不安全增删快，随机访问慢
Vector动态数组安全同步方法，性能较低
Stack数组（继承Vector）安全LIFO结构，push/pop操作

ArrayList vs LinkedList：

  • 随机访问：ArrayList O(1)，LinkedList O(n)
  • 头部插入：ArrayList O(n)，LinkedList O(1)
  • 内存占用：ArrayList连续空间，LinkedList节点开销

2. Set接口 ​

特点：不允许重复元素，最多一个null值

实现类底层结构排序特点
HashSetHashMap无序最佳性能，基于hashCode
LinkedHashSetLinkedHashMap插入顺序保持插入顺序
TreeSetTreeMap自然/定制自动排序，实现SortedSet接口

重要特性：

  • 判断元素相等：equals()和hashCode()必须一致
  • TreeSet要求元素实现Comparable或提供Comparator

3. Queue接口 ​

特点：FIFO（先进先出）结构，两端操作

实现类特点
LinkedList可用作Queue/Deque实现
PriorityQueue优先级队列，按自然顺序或Comparator
ArrayDeque双端队列，高效数组实现

常用方法：

java
// 抛出异常的方法
boolean add(E e);    // 队尾添加
E remove();          // 移除并返回队首
E element();         // 获取队首

// 返回特殊值的方法
boolean offer(E e);  // 添加元素
E poll();            // 移除并返回队首
E peek();            // 获取队首不删除

三、Map接口 ​

键值对集合，键唯一，值可重复

实现类底层结构排序线程安全
HashMap数组+链表/红黑树无序不安全
LinkedHashMap链表+哈希表插入/访问顺序不安全
TreeMap红黑树键排序不安全
Hashtable哈希表无序安全
ConcurrentHashMap分段锁无序安全

HashMap重要特性： ​

  • JDK8+：当链表长度>8时转为红黑树
  • 初始容量16，负载因子0.75（扩容阈值=容量*负载因子）
  • 键对象必须正确实现hashCode()和equals()

TreeMap特性： ​

  • 键必须实现Comparable接口或提供Comparator
  • 提供子视图方法：subMap(), headMap(), tailMap()

LinkedHashMap特殊构造： ​

java
// 按访问顺序排序（LRU缓存）
new LinkedHashMap(16, 0.75f, true);

四、迭代器(Iterator) ​

遍历集合的标准方式

基本用法： ​

java
Iterator<String> it = list.iterator();
while(it.hasNext()) {
    String item = it.next();
    if(/*条件*/) {
        it.remove(); // 安全删除当前元素
    }
}

ListIterator（仅List可用）： ​

  • 双向遍历：hasPrevious(), previous()
  • 获取索引：nextIndex(), previousIndex()
  • 修改元素：set(E e)

六、比较器(Comparator) ​

1. Comparable接口 ​

自然排序，在类内部实现：

java
class Person implements Comparable<Person> {
    private String name;
    private int age;
    
    @Override
    public int compareTo(Person o) {
        return this.age - o.age; // 按年龄排序
    }
}

2. Comparator接口 ​

定制排序，独立实现：

java
Comparator<Person> nameComparator = new Comparator<>() {
    @Override
    public int compare(Person p1, Person p2) {
        return p1.getName().compareTo(p2.getName());
    }
};

// Java 8+ Lambda简化
Comparator<Person> ageComparator = (p1, p2) -> p1.getAge() - p2.getAge();

比较器链： ​

java
Comparator<Person> compound = Comparator
    .comparing(Person::getLastName)
    .thenComparing(Person::getFirstName);

七、线程安全集合 ​

1. 传统线程安全集合 ​

  • Vector：同步方法实现的List
  • Hashtable：同步方法实现的Map
  • Collections.synchronizedXXX：包装器模式

2. 并发集合（java.util.concurrent） ​

类对应非线程安全类特点
CopyOnWriteArrayListArrayList写时复制，读操作无锁
ConcurrentHashMapHashMap分段锁（JDK7），CAS+红黑树（JDK8+）
ConcurrentLinkedQueueLinkedListCAS实现的无界非阻塞队列
BlockingQueue-阻塞队列接口
ArrayBlockingQueue-有界阻塞队列（数组实现）
LinkedBlockingQueue-可选有界/无界（链表实现）

八、最佳实践 ​

1. 集合选择策略 ​

  • 随机访问多：ArrayList
  • 增删操作多：LinkedList
  • 需要排序：TreeSet/TreeMap
  • 需要插入顺序：LinkedHashSet/LinkedHashMap
  • 去重存储：HashSet
  • 键值存储：HashMap
  • 缓存实现：LinkedHashMap（accessOrder=true）

2. 性能优化 ​

  • 初始化集合时指定容量（减少扩容）
java
new ArrayList<>(100);  // 指定初始容量
new HashMap<>(32, 0.8f); // 初始容量+负载因子
  • 避免在循环中多次调用size()（尤其LinkedList）
  • 使用isEmpty()代替size() == 0（更清晰，性能相同）

3. 注意事项 ​

  • 集合判空：优先使用isEmpty()而非size()
  • 集合遍历：避免在迭代中修改集合（除通过Iterator的remove）
  • 正确实现：存储在HashSet/HashMap中的对象必须正确重写hashCode()和equals()
  • 泛型使用：明确指定泛型类型避免运行时异常

java
List<String> names = people.stream()

java
// 代替匿名类
Collections.sort(list, (a, b) -> b.compareTo(a)); 

// 遍历集合
list.forEach(item -> System.out.println(item));

3. 新集合工厂方法（Java 9+） ​

java
List<String> list = List.of("A", "B", "C");

4. Map增强方法 ​

java
map.putIfAbsent(key, value);         // 不存在时添加
map.computeIfAbsent(key, k -> new ArrayList<>()); // 自动创建
map.getOrDefault(key, defaultValue); // 安全获取
map.forEach((k, v) -> System.out.println(k + ":" + v));

十、常见问题解答 ​

1. ArrayList扩容机制 ​

  • 初始容量10
  • 扩容公式：newCapacity = oldCapacity + (oldCapacity >> 1)（1.5倍）
  • 扩容操作：创建新数组并复制数据（Arrays.copyOf）

2. HashMap并发问题 ​

  • JDK7：并发put可能导致环形链表（死循环）
  • JDK8+：解决死循环问题，但仍有数据丢失风险
  • 解决方案：使用ConcurrentHashMap或同步控制

3. 如何选择List实现 ​

  • ArrayList：读多写少，随机访问频繁
  • LinkedList：写多读少，经常在头/尾操作
  • Vector：遗留代码或需要同步（推荐用Collections.synchronizedList替代）

4. 集合与数组转换 ​

java
// List转数组
List<String> list = new ArrayList<>();
String[] array = list.toArray(new String[0]);

// 数组转List（固定大小）
List<String> fixedList = Arrays.asList(array);

// 可修改List
List<String> modifiableList = new ArrayList<>(Arrays.asList(array));

重要提示：Java集合框架是面试重点，深入理解各实现类的底层原理和适用场景对实际开发至关重要。建议结合源码学习数据结构实现。
